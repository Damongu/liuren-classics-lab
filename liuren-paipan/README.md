# 六壬排盘器 v0.1

算法现代 · 规则宋制。为《六壬大全》伴读而写，**每条规则都能指回底本原文**，
底本自相矛盾处不静默、不和稀泥，一律做成开关 + 在盘上打「⚠ 分歧」。

纯标准库，无第三方依赖。Python ≥ 3.10。

## 一分钟上手

```bash
cd liuren-paipan

# 抽象排盘：底本写法「甲子日卯时子将」
python3 -m liuren pan --day 甲子 --shi 卯 --jiang 子

# 底本写法「某加某」：甲辰日戌加寅
python3 -m liuren pan --day 甲辰 --jia 戌加寅

# 真实时空：钟表时 + 地点（自动算地方平太阳时、中气月将、实际日出日入）
python3 -m liuren pan --time "2026-09-07 14:30" --place 成都

# 排完直接落一张 Obsidian 课例卡到 ../六壬vault/30-课例/
python3 -m liuren pan --day 甲子 --shi 卯 --jiang 子 --card --question "为何取午发用？"

# 逆向找靶盘：我要一个涉害·察微，且三传带空亡，并落到 2026 年成都的真实时刻
python3 -m liuren find --keshi 涉害 --sub 察微 --kong y --realize 2 --place 成都

# 某日十二局全景（对照底本"某日某加某"最好用）
python3 -m liuren ke --day 甲子 --year 2026

# 720 课结构分布 / 真实时间频率（算稀有度）
python3 -m liuren stat --sub
python3 -m liuren stat --real --place 成都 --year 2026
```

## 为什么先有 720 课，再有真实时间

天地盘是刚体旋转：一组「天盘 X 加地盘 Y」就锁死整盘。
课式与三传**只取决于日干支 + 月将加时的相对位移 k**，昼夜只影响天将。
所以 60 × 12 = **720 课**穷尽了全部结构 —— 底本自己也这么说：

> 六壬总计七百二十课，内合元首课凡一百一十有五。——第六册 元首课

于是逆向检索不必在真实时间里等：先在 720 里挑结构（`find`），再反解出真实时刻
（`--realize`）。这也是「理论期不需要真实盘」的技术依据。

## 口径与依据（每条都可回改）

| 项 | 默认 | 依据 | 开关 |
|---|---|---|---|
| 历法 | 现代天文算法（VSOP 简化太阳视黄经） | 你的裁定：算法用今，规则用古 | — |
| 月将 | **中气换将** | 第六册元首课：「此课必正月仍用子将也，不然发用何云旺相？」 | — |
| 时辰 | **地方平太阳时**（按经度，不做均时差） | 你的裁定：成都不是东八区 | `--lon/--lat/--tz` |
| 昼夜 | **实际日出日入** | 第十册第三十九法：「日出日入之时极准」，并批评「止以卯为日出、酉为日入」 | `--daynight fixed` |
| 贵人 | **通行表**（甲戊庚牛羊…） | 第一册「先天贵神」歌自云「其说甚有理，而近不用」；且第六册元首课例反推为通行表 | `--guiren book` |
| 涉害孟仲季 | 按**所临地盘宫** | 第六册涉害课「从地盘历数归本家」 | `--shehai-class shen` |
| 涉害深浅 | 自所临宫**前行**至本家（首尾不计），累计与**起点宫五行相同**的项数 | 第六册涉害课订讹：「午加庚金，前行历酉、辛金二重归本家地盘午位」 | — |
| 涉害数法表 | **课经层**（巳不计戊土） | 订讹层「亥加丑…五重」要求巳不计土；观月经层「巳上戊土…共四重」要求巳计土 | `--shehai-table guanyue`（Options） |
| 比用格覆盖 | **开** | 第六册涉害课比用格 + 第十一册第九十三法 | `--no-shehai-bihe` |
| 别责柔日 | 支前三合（顺数第五位） | 第六册别责课：「未日三合前一辰即亥字为初传」 | `bieze_rou` |
| 日界 | 子时换日（23:00） | **底本未明言，规格待考项**，盘上会标 | `--day-boundary midnight` |

## 已知分歧（不改代码去凑）

1. **元首课 119 vs 底本 115**。已排除的猜想：八专日元首 12 条、癸丑日元首 5 条、
   四课不备元首 35 条 —— 都不等于 4。待唐宋层佐证书入库后再判是底本笔误、
   传统计法另有约定，还是我们的元首边界宽了 4 条。→ vault `70-待查`
2. **庚子日午加庚**：第六册涉害课订讹说「取午发用」（纯涉害），同册比用格又把庚子
   列入「皆用比，不用涉害」。两说都能算：默认取戌（比用格），`--no-shehai-bihe` 取午，
   盘上打「⚠ 分歧」并写清两边依据。
3. **巳是否兼计戊土**：订讹层「亥加丑…辰、戊、未、己、戌土五重」要求巳**不**计土
   （否则应为六重）；同册所引「观月经」「巳上戊土……共四重」却明计巳土。两层各自
   自洽而互斥 —— 默认课经层，`shehai_table="guanyue"` 可切另一层。
4. **孟仲季按宫还是按神**：订讹层「取四孟**上神**发用」＝按所临宫（默认）；
   观月经「己丑日卯时……以巳为初传，是巳为孟故」却是按上神本身。
   两说在该例同归一神，故先并存，`--shehai-class shen` 可切。
5. **见机 vs 缀瑕的命名**：深浅相等时，订讹层取临孟（见机），课经层「刚日以日上先见神
   为用……名曰缀瑕」。底本甲午日例两说同归辰，故默认订讹层；若两说分歧，盘上打「⚠」。
6. **别责柔日取神**：底本自己就说「独不用三合上之神，何也？存疑」。
7. **日界**：底本未明言子时换日还是子夜换日，默认 zi23 并在盘上标「规格待考项」。
