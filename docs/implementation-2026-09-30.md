## 2 Agent 骨架

`agents/AGENTS.md` 为规则唯一真源，根 AGENTS.md 指向它；旧完整规则与旧 README 归档。
首个凝神子档含身份、术语、句式、引证范围和冲突预警五段，以及三份系统角色档。
Pi 0.99.1 参数经本机核验，使用两个 append-system-prompt 与显式扩展加载。

扩展提供 source/validate 两个真实工具，按环境固定当前书魂，不接受模型冒充复盘官；
跨书拒绝时挂号。直接 write/edit 底本会被扩展阻止，原文 hash 继续核验。
此拦截针对正常 Pi 文件工具，不声称能把拥有任意 shell 权限的模型变成文件系统沙箱。

结构化输出检查器验证原句、锚点、待核提示、证据标签、共名词六壬义和旁通上限。
八个诱导/虚构/越界用例均须拒收；这属于确定性契约测试，不是模型生成行为保证。

## 3 训练闭环

独立 `curriculum_v3.py` 接在 tutor.py 和既有 webapp 上，保留旧九关及状态。
基础体检12题全对才免修；L1–L6 每轮12题至少11题正确，随后白话复述通过才过关。
题目、答案、随机采样与首答结果由服务端保存，浏览器不提交得分；刷新可恢复，
重复提交不重复记分。错题1/3/7/21天复现，复现再错撤销复述状态，原答保留。

L1 九宗门按等概率轮换；L2 计重/异说与贵人天将；L3 遥克、别责、伏吟、返吟；
L4 题题附教学设例年命，按景祐行年支法确定机械答案，断辞用途留复述核对。
L5 原文锚定的断辞组织；L6 先独立作答再看完整校注本对照，注家自动段归属仍待核。

开放文义不假装自动判对：结构及三条原文引证通过后标待人工，用户逐项确认原文义、
理由边界与证据层次，并留具体评语；未人工验收不能通关。结课测固定5例留出，
4例全对且剩余无原文义/证据原则错误才能通过。

新增真实原文锚点导读，旧导读保留为历史。v3 开场与收尾参数接入新成绩投影，
复用旧复盘规则，另接 R12–R14 导读回执检查。流程提案仍需用户批准。
