# pi 分支统一验收

本轮范围为原设计 A–E：底本、Agent、训练、八张禄命辅助卡和十二书魂。
只改本地 pi；原 Word、旧学习成绩及另一工作区保留。尚未推送远程。

## 启动与浏览

在当前仓库根目录执行：

```powershell
.\启动训练.ps1
```

浏览 http://127.0.0.1:8765/catalogue.html 。选书魂查看五段规则和原文示例，
选择八张卡查看界说、断辞用途、出处及易混淆点，再点击六关训练。
选中书魂后可复制独立会话的启动命令；默认书魂为凝神子。
更换主读底本才手动选书；讲解中的跨书讨论由主讲自动调用liuren_discuss，结果带回原会话。
课堂互动及验证边界见docs/自动课堂.md。

本机专属环境：`D:\术数\六壬\.conda\envs\ai-env\python.exe`。
启动器自动从 Conda 登记寻找，或设置 `LIUREN_PYTHON`。

## 模型验收的当前阻塞

Pi的只读就绪检查返回 `not_ready / credentials_not_configured`，没有配置DeepSeek凭据。
因此尚未调用模型，不能把检查器拒绝诱导等同于DeepSeek课堂表现通过。
已经准备24条实际Pi用例：十二书魂原文调用、八条诱导、四条跨书诱导。
在Pi自身凭据系统配置后运行：

```powershell
.\验收.ps1 -Model
```

模型测试限制工具为原文检索和讲解检查，关闭持久会话；跨书测试写临时挂号。
自动检查只核验JSON决策及工具调用，原文解释质量、真实四拍课堂及长会话稳定性仍须你验收。
报告在 `docs/model-acceptance.json`，原始模型轨迹在 `artifacts/qa/model/`。
不在仓库或聊天中保存密钥，也不查找其他项目的凭据或切换后端。

混排上下文，由复盘官核查。旧frontmatter的宽行范围只作历史，不再支配工具检索。
