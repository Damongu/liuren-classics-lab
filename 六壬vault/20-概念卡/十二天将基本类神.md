# 十二天将基本类神

## 最短解释

天将的基本类神先确定所问事项属于哪一类，不能由单一天将直接判断成败吉凶：

| 天将 | 基本类神 |
| :--- | :--- |
| 贵人 | 权贵、诏命、福德 |
| 螣蛇 | 惊恐、怖畏、怪异 |
| 朱雀 | 文书、口舌、官府 |
| 六合 | 和合、婚姻、阴私 |
| 勾陈 | 争讼、战斗、田土 |
| 青龙 | 钱财、庆贺 |
| 天空 | 欺诈、虚诞、不信 |
| 白虎 | 疾病、死丧、折伤 |
| 太常 | 冠带、衣服、仕宦 |
| 玄武 | 遗失、盗贼、奸宄 |
| 太阴 | 隐蔽、阴私、金帛 |
| 天后 | 妇女、后宫 |

引申必须先锁定上述原典核心，再按具体占题映射对象，最后结合所乘天盘神、所临地盘宫、
旺衰、生克及课传判断表现。现代事物只能标为“今人同构引申”，不能倒写成古书原意。

## 禄命锚点

十二天将整体在禄命法中没有严格同层对应，不能当作十二个固定神煞使用。贵人、六合、
天空、太阴等虽与其他术数共享名称，在六壬中均须按天将层读取。

## 出处定位

- 十世纪《占事略决》第4章《十二将所主法》：完整列十二将及其基本所主。
- 北宋《景祐六壬神定经》下卷《释天官第二十九》：详列各将本家、五行、基本事项及
  旺相休囚变化。
- 北宋《景祐六壬神定经》下卷《释将传第三十六》：简列传见十二将的事项类别。
- 北宋《武经总要》后集卷二十《占候五·八专例》：六壬本体规则，保存兵占中的将象；
  与《景祐》同属杨维德官修系统，不算独立互证。
