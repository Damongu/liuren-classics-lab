# 式盘最小模型

## 本课目的

本课只建立后续课程共用的盘面语言，不要求计算三传，也不单独刷题。

## 四层对象

| 层 | 是什么 | 是否移动 | 最小作用 |
| :--- | :--- | :---: | :--- |
| 地盘 | 固定排列的十二地支宫位 | 否 | 提供十二个固定坐标 |
| 天盘 | 十二月将随“月将加时”覆盖到地盘 | 是 | 给每个地盘宫配置一个上神 |
| 四课 | 从日干、日支各自向上取神形成的四组上下关系 | 随盘而定 | 提供取初传的候选关系 |
| 三传 | 初传、中传、末传 | 随课而定 | 表示事机展开的三个次序 |

另有“十二天将”层：贵人、螣蛇、朱雀等依附在天盘神上。它不参与天地盘的基本旋转，
也不应与子、丑、寅等天盘神混称。

## 最短调用链

```text
日干支、占时、月将
→ 月将加时，形成天地盘
→ 日干经寄宫取得地盘坐标
→ 从日干与日支向上读取天盘神，形成四课
→ 依九宗门选择初传
→ 初传在天盘上连续取上神，形成中传、末传
→ 最后再布十二天将
```

这只是课程地图。每一步的操作、证据和例外，分别在后续概念课完成四拍。

## 术语边界

- “神”：在“上神”“天盘神”中，通常指子至亥十二支及其月将名。
- “将”：在“天将”中，指贵人至天后十二将。
- “临”：天盘某神覆盖在地盘某宫之上，如“丑临辰”。
- “寄”：把天干转换成可在地盘读取的固定代理坐标，如“乙寄辰”。

## 唐宋证据

- **一手·基准层**：《太白阴经》卷十《玄女式》：“以月将加正时，课日辰用为天乙，
  所理十二神，将以断吉凶成败。”
- **一手·基准层**：《占事略决》第1章《四课三传法》：“常以月将加占时，视日辰阴阳，
  以立四课。”
- **一手·基准层**：《景祐六壬神定经》下卷《释用式第三十一》：“右手转月将以加正时。
  视日辰上下阴阳，以立四课。”

这些材料能硬证“月将加时 → 四课 → 三传”的基本结构；“四层对象”“固定坐标”等措辞
是现代教学拆解，不冒充古籍原词。当前录文均须回原书影像核字。

## 本课边界

学完只需能区分地盘、天盘神、四课、三传、十二天将，并知道它们的先后关系。不要在本课
追问每层的完整算法；后续依次学习：

1. 寄宫、旬空、旬遁；
2. 天地盘；
3. 四课；
4. 贼克与比用；
5. 九宗门其余规则；
6. 十二天将；
7. 真实时空起课。
