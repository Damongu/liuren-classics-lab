# 涉害涉归本家

## 先看它在取用链中的位置

涉害不是脱离贼克另造候选，而是贼克、比用仍不能唯一取用时的第二次消歧：

```text
四课先取相克
→ 只有一个同向克候选：直接取该课上神
→ 有多个同向克候选：先用比用筛选
→ 俱比或俱不比：再用涉害比较深浅
```

这条递进顺序见唐《太白阴经》卷十《玄女式·推四课法》、十世纪《占事略决》第二章
《课用九法》、北宋《景祐六壬神定经》下卷《释用式第三十一》，属于一手硬证。
《武经总要》后集卷二十《入式课加临永用例》亦载同序，但与《景祐》同属杨维德主持，
不能另算独立互证。上述录文均为机器切分，引用时须回原书影核字。

## 教程工程标准

比用后仍为俱比或俱不比，进入涉害：

1. 对每个候选上神，找到它现在所临的地盘宫。
2. 从所临宫的下一宫顺行，到候选上神自己的本宫为止；起点、终点不计。
3. 沿途逐宫展开地支本气与十干寄宫，并依原四课的克向逐项计重：
   - 多重下贼上：数沿途能克候选天神的地神。
   - 多重上克下：数候选天神所克的沿途地神。
   - 日干寄宫只确定第一课天神所临的地盘起点，不提供计数五行。
4. 取重数最多的候选上神发用。
5. 重数相等，再按所临地盘宫取孟；无孟取仲；无孟仲方取季。
6. 最高同级仍有多个，才叫复等：刚日从干两课取先见候选，柔日从支两课取先见候选。
7. 教程默认不追加《大全》后置比用格。

角色不要混淆：**归本家的主体是候选上神**；其所临地盘宫只提供起点，计数关系来自
原四课的上下克向。操作上是计数指针沿地盘顺行，不是下神移动。

## 两种“深浅”不能混讲

### 十世纪直取法

《占事略决》直接规定：

> 加孟为深，加仲为半，加季为浅。

这是明确规则，但现有文本没有说明**为什么孟必然最深**。同一课的天盘作统一位移，
各候选从所临宫归本家的路程长度相同，故孟仲季不能表示归本家路径长短。《占事略决》
在其他占法中又使用“孟始发、仲半道、季既至”以及“孟不可信、仲半信、季可信”，说明
孟仲季首先是阶段坐标，具体价值顺序依占题另定，并不存在跨题通用的“孟最深”公理。

旧说“孟为四生、时令之首，所以受害最深”完整保留：此理据见《六壬大全》第六册
《涉害课》的后出解释，可以说明见机格为何借“事之初起”取象，却不能从四课克向、
路径长度或实际克数推出孟必深于仲季。用西方黄道四季起点作反模型，同样可以把季节
起点赋予相反价值；该反模型只证明“季首不能逻辑必然推出最深”，不作六壬源流证据。

### 《大全》逐位计重法

《六壬大全》把“深浅”落实为归本家途中实际遇到的克数：

> 涉者，度也。害者，克也。
>
> 从地盘历数归本家，受克深者。

因此它的内部机制是：

```text
候选天神归本家
→ 沿途保持原四课的上下克向
→ 逐项累计地支本气与寄干之克
→ 克数多者为深
```

这解释了“为什么数克”，也保持了贼克法的施受方向；但“为什么必须归本家、为什么
顺行取这条路径”的创制来源目前待查，逐位计重细法仍无宋据。

## 为什么教程采用逐位计重

这是工程选择，不是断代结论：

1. 它延续贼克的原始克向；比用、涉害始终只在原候选内继续消歧。
2. 深浅由可复核的实际克数产生，不必预设“孟天然最深”。
3. 720课中，直取法入涉害82课为孟59、仲23、季0；逐位计重为孟50、仲13、季19。
4. 两法在76个最终涉害课中有22课初传不同，占28.9%，中末传也随初传连锁改变。

证据边界必须同时保留：直取孟仲季有十世纪一手硬证；逐位计重在内部逻辑和算法覆盖上
更完整，但目前无宋据。不能把“教程采用”改写成“宋代已证”。

## 复习

- Q：从哪里起数，到哪里停止？
- A：从候选上神所临地盘宫的下一宫起，顺行至该上神本宫止；首尾不计。
- Q：何时才用孟仲季？
- A：逐位计重相等时。
- Q：教程是否追加比用格？
- A：默认不追加；该规则在《大全》内部存在冲突。
- Q：逐位计重与孟仲季仍同等时怎样取？
- A：进入复等；刚日取日侧先见候选，柔日取辰侧先见候选。这是日辰侧裁决，不是重做阴阳比用。
