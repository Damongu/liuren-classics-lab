# 对校矩阵 · 五个判别点

这张表是整个知识库的**主工作面**。书到手之后，真正的活不是"读完"，
而是**在同一个问题上把各书的答案摆在一起**。

填法：一格一句原文（带卷篇定位），不写解释。解释写进对应考据卡。
拿不准就留空——**空格比猜测有价值**。

这五处是"明本是否改过"最灵敏的探针：规则简单、表述固定、各书都必然要交代。

## 派生结论区

### 已成立

#### 结论 A：①⑤ 唐宋一贯，明本未改 —— 可结项
起课立四课的定义、昴星"刚仰视酉上／柔视从魁所临"及其三传顺序，
**唐（759）→ 10 世纪 → 景祐（1034）→ 武经总要（1044）四本零分歧**，
明《六壬大全》亦同。这两项不必再查。

唯一措辞差异是柔日的动词：太白／武经作「**伏视**」，占事略决／景祐作「**俯视**」，
占事略决另作「所临**下神**」。三者所指相同，属抄写用字，不构成规则分歧。

#### 结论 B：「孟仲季」与「先干后支」**不是两说，是两个环节** —— 修正旧记录
这是本轮最重要的更正。此前书卡把《太白阴经》的「先干后支」当成
与「孟仲季」对立的另一种涉害取用法，**这是概念错误**。

实际结构是两层：

1. **深浅的量度**：怎么算哪个"涉害更深"。
2. **量度后仍相等的裁决**：depth 打平了取谁。

「孟仲季」属第 1 层，「先干后支」属第 2 层。二者**层级不同，不构成矛盾**。
铁证是《占事略决》**同时具备两者**：第三法用孟仲季定深浅，第四法用"先举者"裁平局。

由此进一步得到：

- 四部唐宋硬本中，**只有《占事略决》定义了深浅量度，而它给的正是孟仲季**。
- 太白、景祐、武经总要三本都只说"涉害深"，**对如何量度保持沉默**。
- 因此：**"宋制涉害取孟仲季"有硬本支持，且无任何唐宋硬本与之矛盾。**

→ 排盘器现有口径（涉害按孟仲季）**得到硬本支撑，不必改**。
→ 但须记明这是**孤证**：唐宋硬本中仅《占事略决》一处，
   且该书是日本安倍晴明的概说抄本，非中土官修。证据强度：**可用，但单薄**。
→ 「先干后支」应作为**独立开关**加入排盘器（三本一致，比孟仲季证据更强），
   而非孟仲季的替代项。详见 [[待查清单]]。

#### 结论 C：贵人表在唐宋之间发生了一次明确迁移
唐本与宋本的分组不同，且迁移点很干净：

| | 甲戊 | 庚 | 辛 |
| :--- | :--- | :--- | :--- |
| **唐·太白阴经** | 大吉／小吉 | ← **与辛同组**（胜光／功曹） | 胜光／功曹 |
| **10c·占事略决** | 大吉／小吉 | → **已并入甲戊** | 独立 |
| **宋·景祐** | 大吉／小吉 | → 并入甲戊 | 胜光／功曹 |
| **宋·武经总要** | 昼丑夜未（＝大吉／小吉） | → 并入甲戊 | 昼午夜寅（＝胜光／功曹） |

**迁移的实质**：唐本是「甲戊 ／ 庚辛」两组；十世纪起变为「甲戊庚 ／ 六辛」。
即**庚被从辛组取出、并入甲戊组，而辛留在原位不动**。

明本「甲戊庚牛羊」口诀 = 宋本，**不是唐本**。
这是本矩阵中断代最锋利的一格：见到「庚辛同组」即指向唐层或唐层遗存。

另注：《景祐》与《武经总要》两部北宋官修书贵人表**100% 等价**，
只是前者用将名（大吉／小吉）、后者用地支（丑／未）表述。互为独立印证。

#### 结论 D：昼夜界定有两个口径，且直接影响排盘 —— 需处理
- **天文口径**：星没为旦／星出为暮（太白、武经总要）。随节气与纬度浮动。
- **时段口径**：昼寅至酉／暮戌至丑（占事略决）。固定，可机械实现。

两个北宋官修本都用**天文口径**。排盘器目前用固定时段（卯至申／酉至寅），
既非唐宋任一本，也与明本略异 —— **这是一处实际口径偏离，须校**。
详见 [[待查清单]]。

#### 结论 E：「九宗门为什么是九」—— 十世纪的九与后世的九**不是同一个九**
这条直接回应最初的核心疑问。

《占事略决》第 2 章题作「**课用九法**」，也是九门，但清单与后世不同：

| # | 十世纪《占事略决》九法 | 后世九宗门 |
| :--- | :--- | :--- |
| 1 | 贼克（下克上／上克下） | 贼克 |
| 2 | 比用 | 比用 |
| 3 | 涉害（孟仲季定深浅） | 涉害 |
| 4 | **涉害俱等取先举** ← 单列为一门 | 遥克 |
| 5 | 遥克 | 昴星 |
| 6 | 昴星 | **别责** ← 新入 |
| 7 | 伏吟 | 八专 |
| 8 | 反吟 | 伏吟 |
| 9 | 八专（＝"五柔日"） | 反吟 |

差异有二，且互相咬合：

1. 《占事略决》把「涉害」与「涉害俱等的裁决」**拆成第三、第四两门**；
   后世**合并为"涉害"一门**。
2. 《占事略决》**没有别责**；后世**有别责**。

而**别责恰恰在北宋出现**：《景祐》（1034）明确设「别责之课，其数有九」，
《武经总要》（1044）昴星例末亦载别责。唐《太白阴经》与十世纪《占事略决》**均无**。

→ 推论：后世九宗门的"九"，是在北宋**合并涉害二门、腾出位置给新入的别责**之后形成的。
   数目守恒为九，但**成分已经换过一味**。
→ 因此"九宗门"这个九**不是一个自古如此的神圣数目**，而是一次结构重组的结果。
   这解释了为何各书对"九"的解说总有龃龉。

**这是一条待验推论，不是定论。** 需补的证据：
- 别责在北宋之前是否真无？须查《玉门经》《金匮经》残文（《武经总要》大量引此二经）。
- 「九」这个数目是否在《占事略决》之前就已固定？若唐本无"九法"之称，
  则"九"本身就是十世纪的构造。
- 立项见 [[待查清单]]。

## 第六个判别点（新增）：三刑表里有没有自刑

原五点都在**起课发用**层。这一点在**术语层**，由《武经总要》扩容后新增。
伏吟三传必须用刑，所以「刑」的定义直接影响排盘结果，是硬判别点。

| 书 | 断代 | 支支互刑 | 辰午酉亥自刑 | 给理据吗 |
| :--- | :--- | :--- | :--- | :--- |
| 太白阴经·元女式 | 唐·约759 | 只说「以刑及冲用为传」，无表 | 未提 | 无 |
| 占事略决·第12章 | 十世纪 | **全列** | **列** | 无，只列结果 |
| 景祐·释刑第十六／释六情第十一 | 1034–38 | 无表 | **列，且给理据**（翼奉五行穷极说） | **有** |
| 武经总要·卷十七风角 | 1044 | **全列** | **不列** | 无 |

### 结论 F：六壬的「刑」是两套系统的合流

- 支支互刑（子卯／寅巳申／丑戌未）来自十二支相刑表，风角类书通用；
- 辰午酉亥自刑来自翼奉「金刚火强、木落归本、水流趋末」的五行穷极说，
  四支恰是水火金木四局的极位。土的落点是**戌**，不在自刑之列——五行有五，自刑只四，缺口在土。

两者道理完全不同，后世并列写成「三刑」掩盖了来源差异。
**《景祐》是唯一给理据的书**，因此也是唯一在伏吟条里对自刑作分支处理的书。

### 结论 G：据此修正了排盘器一处实错

《景祐·释用式第三十一》伏吟条给出完整分支。原排盘器在**有克**分支取天盘上神作中传，
而伏吟天盘即地盘，导致六乙日得「辰辰辰」、六癸日得「丑丑丑」。
按《景祐》「尽刑为三传」改为刑链后：六癸日 → 丑戌未；乙丑 → 辰丑戌；乙酉 → 辰酉卯。
测试 18/18 通过。详见 [[自刑与三刑-两套刑法的合流]]。

> 附带校出一字：《景祐》「**己**癸二柔日课有相克」当作「**乙**癸」。
> 按寄宫穷举，六十日中第一课有克者只有乙（寄辰，辰土受乙木克）、
> 癸（寄丑，丑土克癸水）两组；己寄未，土土同类不可能有克。
> 这个结论不依赖版本对照。

## 对本矩阵旧结论的影响：一处措辞要改

《武经总要》占候五卷署**司天少监杨维德**，而《景祐六壬神定经》里说话的也是**太史杨维德**
（见 [[杨维德-两部北宋官修书的同一编者]]）。两书**同编者**。

因此凡本矩阵及 [[贵人表唐宋分化-断代锚点]] 中写作
「两部北宋官修书**互为独立印证**」的地方，都**不成立** ——
那是同一批人的两次表述，等于一个证人说了两遍。

**修正后的证据结构**：
- 《景祐》＋《武经总要》＝ **北宋官方口径**（一个证人，两个载体，可互校字句）；
- 《占事略决》＝ **独立第三证**（域外传承，不属司天监系统）；
- 《太白阴经》＝ **唐代对照组**。

好消息是：贵人表上《占事略决》与两部官修书一致，
所以「北宋口径是甲戊庚／六辛」这个结论**仍然站得住**，
只是它的证据从「三个证人」变成「两个证人」。
