# 互校污染规则（第二拍强制前置检查）

这张卡不是知识，是**流程约束**。凡要拿一部书去校《六壬大全》，先过这里。

## 为什么要有这条规则

发现了一条闭环：

```
明  《六壬大全》 ──全收──▶ 《六壬心镜要》
                                  │
清  今本《大六壬心镜》 ◀──据《大全》及程鹏南本改正──┘
```

卷八有具名校记「今伟堂据《大全》及程鹏南本改正」。也就是说：

> **今本《心镜》里有一部分字句，本来就是照着《六壬大全》抄回去的。**

拿这些字句去"验证"《六壬大全》，等于让《大全》给自己作证。
校出来的吻合是**自造的**，不是独立证据。这类假吻合最危险，因为它长得跟真证据一样。

## 规则零：先分清「改了字」和「加了注」★

**这是 2026-09-08 补的，因为最初把两者混为一谈，导致《六壬断案》212 条
纯校注被误判成污染、几乎整本书被错误排除。**

| | 判据 | 含义 | 证据力 | 处置 |
| :--- | :--- | :--- | :--- | :--- |
| **字句被改**<br>`污染: true` | 「据…改」「据…补」「今据…校正」「恭校」「疑脱」「疑衍」 | 原文**已被改动**，你看到的字可能不是古人写的 | **打折／不可作独立证据** | 不得用于反校《大全》 |
| **混入今注**<br>`今注: true` | 「郑按」「伟堂按」「爱函按」「缘生谛」「郇注」「◎」 | 只是后人**加了一段议论**，原文字句未动 | **不打折** | 剥离注文后正常使用 |

判断的关键一问：**这条校记是在"说明我改了什么"，还是在"发表看法"？**

- 「伟堂**据**程鹏南本**补入**」→ 改了字 → 污染。
- 「伟堂**按**：此说恐非」→ 只是看法 → 今注。

同一个人名可以出现在两种句式里，**不能靠人名判定**，只能靠动词。
机器规则见 `../../tools/mark_pollution.py`，扫描结果见各书 `_污染位置表.md`。

## 三条硬规则

### 规则一：见校记即隔离

引用任何辑校本时，先看该处有无校记。凡出现以下字样，该句**不得**用作独立证据：

- 「据《大全》改」「据《大全》及某本改正」
- 「据某本改正」「据某本补」「据…恭校」
- 「疑脱」「疑衍」「疑误」「今改」「今补」「今据…校正」

⚠️ **不要把「今正」「今按」单独当校记**——「今正秋占」是正文，「今按」多为议论。
必须带校勘宾语才算。

处置：正文照引，结论标 `⛔ 循环` 或 `⚠ 校改`，证据等级降为 0（仅作提示）。

### 规则二：证据方向不可回流

| 方向 | 允许 | 说明 |
| :--- | :---: | :--- |
| 唐宋原刻 / 官修 → 校《大全》 | ✅ | 正常方向 |
| 域外未经明清改写之本 → 校《大全》 | ✅ | 《占事略决》属此 |
| 清辑校本**无校记处** → 校《大全》 | ⚠️ | 可用，但等级降一档，需第二独立证据附议 |
| 清辑校本**有校记处** → 校《大全》 | ⛔ | 禁止，循环 |
| 从《大全》辑出的书（如《通神集》系文字）→ 校《大全》 | ⛔ | 同源，禁止 |

### 规则三：吻合要先问"为什么吻合"

第二拍拿到"两书一致"的结果时，必须先答一句：

> 这两处一致，是因为**同源**，还是因为**同真**？

同源（一方抄自另一方、或双方同抄第三方且该第三方即待验对象）→ 无效。
同真（传承独立、地域隔离、年代不同层）→ 有效，可结项。

## 落到答疑流程里的动作

第二拍「佐证」由原来的两步变三步：

```
旧：  找到佐证 → 报告一致/冲突
新：  找到佐证 → ①查校记 ②判方向 ③再报告，并附证据等级
```

输出格式追加一行：

```
证据等级：一手 / 二手 / 二手（有校记，降级） / ⛔ 循环（不采信）
独立性：  同真 / 同源 / 待判
```
