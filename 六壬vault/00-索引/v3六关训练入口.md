# v3 六关训练入口

在仓库根目录运行 `启动训练.ps1`，再打开 http://127.0.0.1:8765/curriculum.html 。
启动器使用六壬专属 Conda 环境；服务默认仅监听本机。

基础体检须一次 12 题全对才免修。L1–L6 每轮 12 题，至少 11/12，并通过白话复述。

| 关卡 | 训练内容 |
| --- | --- |
| L1 | 九宗门课体与三传 |
| L2 | 涉害、贵人、天将 |
| L3 | 遥克、别责、伏吟、返吟 |
| L4 | 年命与行年教学设例 |
| L5 | 有原文证据的断辞组织 |
| L6 | 独立断案与原例对照 |

开放断辞先检查盘面、结构和三条真实原文引证，再由用户核对文义、理由和证据边界。
待人工验收的答案不算通关。错题按 1/3/7/21 天复现；全部关卡完成后有五例留出结课测。
旧九关成绩不折算为新成绩，测试也不写个人成绩。

带读运行 `启动六壬.ps1`，默认载入凝神子书魂和原文检索工具。
《中黄经》目录见 [[10-底本/唐宋层/中黄经/00-中黄经目录|中黄经目录]]。
底本层次与年命异说见 [[70-待查/v3训练待核项|训练待核项]]。
真实模型课堂表现仍待实测。
