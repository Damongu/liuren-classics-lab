# 导读流程·方案（待审批）

本页只是方案。未经用户明确批准，不得据此修改 `AGENTS.md`、当前教学流程、训练器行为
或任何验收标准。

## 一、为什么要加导读

用户反馈「导读过程不够详细」。核查项目后确认：**这不是执行偏差，是规格空缺**。

- 全项目检索「导读」零命中，没有任何一处定义过导读环节。
- [[教学流程复盘]] 当前流程第 2 步只有一句话：「先读《六壬大全》当前条目的原文、注文和
  课图，再解释概念」。除此之外没有任何可检查的动作。
- 于是每节课的读书环节完全靠 agent 临场决定讲多少，节与节之间不一致，也无法复盘。

真正被漏掉的信息，是四拍第一拍「解释」结构上装不下的那部分：

| 缺口 | 具体表现 |
| :--- | :--- |
| 原文定位 | 现在讲的这几句在原书第几册第几篇第几页，讲解与原文哪一行对应，无法自查 |
| 文本身份 | 哪些是明本原刻、哪些在今注剥离区、哪些是今人补入（如总钤），读者分不清 |
| 切分与读法 | 口诀 33 字里哪几字是规则、哪几字是凑韵；课体 2800 字里哪几段现在该读 |
| 推进关系 | 能力序打乱了书序，跳读之后不知道这一条接在上一节的哪个接口上 |
| 跳过说明 | 本节故意不读什么、为什么不读、什么时候回来读，从来没有交代 |

## 二、导读是什么，不是什么

**导读 = 进入原文之前的地图与读法说明。**只做定位、切分和读法交代，不讲规则原理。

| | 归导读 | 归第一拍「解释」 |
| :--- | :--- | :--- |
| 内容 | 这段文字是什么、在哪、怎么读、先读哪块 | 这条规则怎么操作、为什么这样操作 |
| 产出 | 一张读法地图 + 待答问题清单 | 可执行步骤 + 排盘器实例 |
| 禁止 | 禁止提前给出规则结论和待答问题的答案 | 禁止跳过原文直接给步骤 |

这条边界是本方案的核心约束。导读一旦开始讲原理，就会吞掉整节课，并让第三拍的主动
回想失效（答案已经在导读里说过了）。

## 三、导读固定结构（七件套）

| # | 件 | 内容 | 档位要求 |
| :---: | :--- | :--- | :--- |
| 1 | 坐标 | 册／篇／节／原书页；在零基础课序里的课序；上一节完成了什么，本条接哪个接口 | 必给 |
| 2 | 文本体检 | 正文字数；有无今注剥离区；有无盘；是否今人补入；异体字、疑难字、句读风险点 | 必给 |
| 3 | 切块与读法 | 把原文切成若干块，逐块标注性质：规则／例外／修辞凑韵／断语／象辞／课例；标明本节精读哪块、略读哪块、暂时跳过哪块 | 必给 |
| 4 | 生词护栏 | 本条出现但尚未教学的术语，明确「本节只当名词记住，不展开」 | 必给 |
| 5 | 待答问题 | 读完应能回答的 2–3 个问题，只摆问题不给答案 | 必给 |
| 6 | 冲突预警 | 同一规则在《大全》别处另有说法，或与已学内容表面矛盾，先挂号，留到第二拍佐证处理 | B、C 档必给 |
| 7 | 阅读预算 | 本条精读预计用时；导读本身的时间上限 | B、C 档必给 |

跳过必须写原因和回收时点，不允许只写「本节不读」。

## 四、按条目类型分三档

底本 frontmatter 已有 `类型` 与 `盘数`、`今注数`，可直接判档，不需人工判断。

| 档 | 适用类型 | 正文规模 | 导读上限 | 件数 |
| :---: | :--- | :--- | :--- | :--- |
| A | 口诀、名目表、表钤 | < 200 字 | 5 分钟 / 400 字 | 1–5 件 |
| B | 神将条目、神煞条目、毕法条目、赋文 | 200–3000 字 | 10 分钟 / 700 字 | 1–7 件 |
| C | 课体、兵占、分野 | > 3000 字 | 15 分钟 / 1000 字 | 1–7 件，且必须给分区表 |

C 档强制要求分区表：课体条目通常混着定义、象辞、断语、课例、解曰五种文字，阶段 3
只读定义与取用条件，象辞与解曰整段推到阶段 5、6，必须在导读里点明，不能让学习者
以为自己漏读。

导读超上限即视为讲课，当场按 `超时` 打点。

## 五、导读产出物落在哪

| 方案 | 做法 | 评价 |
| :--- | :--- | :--- |
| 甲 | 在底本条目里加 `## 导读` 段 | 与原文同屏，但污染底本区。底本区目前只放原刻正文与今注剥离区，加入 agent 生成内容会破坏「这一区全部可作证据」的前提 |
| 乙（建议） | 新建 `15-导读/`，一条一份导读卡，双链回底本条目与概念卡 | 底本区保持干净；导读可独立改版、可审计、可被 Dataview 统计；代价是多一次跳转 |
| 丙 | 只在对话里说，不落盘 | 零成本，但不可复用、不可复盘，换会话即重来。等于现状 |

建议采用乙，并在底本条目顶部引用行追加一条 `导读：` 双链，补足跳转成本。

导读卡文件名与底本条目对齐，例如
`15-导读/01-第一册 起例/005-涉害法-导读.md`，frontmatter 记 `底本`、`档`、`版本`、
`生成日期`、`回执`（未通过／通过）。

## 六、导读回执（轻验收，不是考试）

导读结束、进入四拍之前，用户用一两句话回答：

1. 这一条要解决什么问题；
2. 本节先读哪块、先不读哪块。

答得出即通过，直接进第一拍；答不出说明导读没起作用，当场按 `导读不足` 打点，
并只重做导读的第 1、3 两件，不重讲全部。

回执**不计入掌握度，不进错题队列**，也不是通关条件。它只是导读自身的效果检查。

## 七、挂进当前流程的位置

当前第 2 步「读《六壬大全》当前条目」拆成 2a、2b 两步，其余步骤不动：

```text
开场简报（retro.py --brief）
→ 2a 导读（七件套，按档限时）
→ 2b 回执（两问）→ 未通过则只重做坐标与切块
→ 2c 原文精读（按导读划定的精读块逐块读）
→ 第一轮四拍
→ Terminal 单项练习
→ 错题定位与第二轮四拍
→ 迁移思考
→ 白话复述验收
→ 最终过关
→ 1/3/7/21 天原题复现
→ 收尾复盘（retro.py --close）
```

一节 60–90 分钟的时间账（B 档）：导读 10 分钟、精读 10 分钟、四拍 30–40 分钟、
练习与讲解 20 分钟。导读吃掉的时间从「反复回头补上下文」里省回来。

## 八、程序支持：`tools/guide.py`（建议新增）

按项目一贯做法，硬结构交程序，判断交 agent。导读七件套里有五件可由程序直接生成。

```bash
python3 tools/guide.py --entry "01-第一册 起例/005-涉害法"   # 生成导读卡骨架
python3 tools/guide.py --check                              # 本节是否已有导读卡
python3 tools/guide.py --list --stale                       # 底本改版后需重生成的导读卡
```

| 件 | 由谁填 | 数据来源 |
| :--- | :--- | :--- |
| 1 坐标 | 程序 | frontmatter 的册／篇／节／页；[[阅读路线图]] 的零基础课序 |
| 2 文本体检 | 程序给量，agent 补字词风险 | 正文字数、`## 盘`、`## 今注剥离区`、`今注数`、`盘数`、`类型` |
| 3 切块与读法 | agent | 需要判断文本性质，不可自动 |
| 4 生词护栏 | 程序给候选，agent 定稿 | `前置` 字段与 `_tutor_state.json` 已达标专项的差集 |
| 5 待答问题 | agent | 需要判断本节目标 |
| 6 冲突预警 | 程序给线索，agent 定性 | 同名规则在其他条目的出现位置 |
| 7 阅读预算 | 程序 | 由档位与字数推算 |

配套改动：`selfcheck.py` 增加一项——若当前节无导读卡或导读卡早于底本条目修改时间，
报「导读缺失／过期」。

## 九、与自我迭代机制挂接

导读质量本身也要能被自动发现，否则又回到「用户先发现问题」。

**新增信号类型**：`导读不足` —— 因原文定位、文本身份、切分或推进关系没交代清楚而
产生的追问、回执失败或读错块。

**新增规则（阈值写死）**：

| 规则 | 触发条件 | 起草提案内容 |
| :--- | :--- | :--- |
| R12 | 单节 `导读不足` ≥ 2 | 修订该档导读模板，补足失效的那一件 |
| R13 | 连续 2 节回执未通过 | 降档或拆节：C 档条目按段拆成两节 |
| R14 | 某档导读连续 3 节超时长上限 | 压缩该档件数或上调时间预算，二者取一 |

三条规则一律只起草提案，仍须用户批准后才改模板，红线不变。

## 十、红线

导读不得：

1. 提前给出规则结论，或泄露待答问题的答案；
2. 引用尚未教学的概念作为解释前提（只能作名词护栏）；
3. 把今注剥离区、总钤等今人内容当作原刻正文导读；
4. 用重绘图冒充原书课图，或不标页码就引原文；
5. 替代第一拍解释、或占用超过本档时间上限；
6. 因导读补充而改变四拍顺序与任何验收标准。

## 十一、收益、风险、回退

**预期收益**：每节读书环节有固定结构，跳读不再丢上下文；原文与讲解逐块对应，用户
可自查 agent 有没有偷换内容；今人补入内容与明本原刻在入口处即被分开，与取证规则
同向加强；导读缺失、失效、超时都能被程序发现。

**风险**：① 七件套全给可能让节奏变慢，尤其 A 档 33 字口诀配 400 字导读显得头重脚轻；
② 导读写多了会变成变相讲课，损害主动回想；③ 581 条底本若一次性预生成导读卡，会产生
大量未经验证的模板文本。

**回退**：导读卡独立存放于 `15-导读/`，停用只需在流程里删掉 2a、2b 两步，底本、概念卡、
训练记录和成绩全不受影响；已生成的导读卡保留备查。

## 十三、批准后的实施顺序

1. 建 `15-导读/` 目录与导读卡模板；写 `tools/guide.py` 与自测。
2. 用当前正在学的一节（旬遁复现或天地盘）实跑一次，检查时间上限是否现实。
3. 实跑通过后，才把 2a、2b、2c 写入 `AGENTS.md` 与 [[教学流程复盘]] 的当前流程，
   并新增 `导读不足` 信号与 R12–R14。
4. 连续三节后复盘：回执通过率、导读用时、`导读不足` 条数，据此决定是否精简件数。

## 附录：A 档导读样例（涉害法，33 字）

以下为按本方案写出的一份 A 档导读，用于判断颗粒度是否合适。**它只做定位与读法，
四个问题一律不给答案。**

**1 坐标**
第一册 起例｜入手法｜涉害法，原书页 8-8，正文 33 字，类型口诀，阶段 3。
在零基础课序里属第 5 课「九宗门其余规则」。上一节已完成贼克、比用与主干三传；本条接的
接口是「四课有克，但比用也定不出唯一用神」这一分支，不是另起一套起课法。

**2 文本体检**
33 字，四句。无今注剥离区，无盘图，全部为明本原刻。
同名条目另见第六册《涉害课》p260-265，2972 字带 2 盘——那是课体与断语，本节不读。
字词风险：「柔」「刚」是阴日阳日的术语，不是形容词；「复等」指涉害深浅相等，不是「重复」。

**3 切块与读法**

| 块 | 原文 | 性质 | 本节 |
| :---: | :--- | :--- | :--- |
| 1 | 涉害行来本家止 | 规则·路径起止 | 精读 |
| 2 | 路逢多克为用取 | 规则·取用判据 | 精读 |
| 3 | 孟深仲浅季当休 | 规则·深浅判定，且是已知口径分歧点 | 精读并挂号 |
| 4 | 复等柔辰刚日宜 | 例外·打平后的备用规则 | 精读 |

四句全精读，不跳过；本节不读第六册课体与断语，等阶段 4 课体期回收。

**4 生词护栏**
孟仲季：本节只当作「寅申巳亥／子午卯酉／辰戌丑未」三组记住，不展开四时旺衰。
见机、察微等后世名目本条不出现，不提前引入。

**5 待答问题（读完自己答，导读不给答案）**
① 「本家」指盘上哪一格？
② 「深浅」在数的是什么东西的个数？
③ 深浅相等时，凭什么在两者之间决定？

**6 冲突预警**
孟仲季判深浅，是按地盘宫位还是按天盘神数，《大全》此处与唐《太白阴经》卷十玄女式的
表述不一致；排盘器为此留了口径开关。此点留到第二拍佐证处理，导读只挂号。

**7 阅读预算**
A 档：导读 5 分钟内，精读 5 分钟，随后进第一拍。
