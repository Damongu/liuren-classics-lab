# 掌握度看板

`mastery` 四级：**生**（没接触）→ **会说**（能复述）→ **会用**（能手排）→ **会辨**（能判断该用哪条规则）。
由 agent 每轮抽查后写回，不靠自我感觉。

## 五个入口

**学得怎么样**

- [[学习画像]]：人话版结论，记录强项、薄弱项、错误模式和训练处方。
- [[训练记录]]：程序生成的题数、正确率和关卡状态，不手改。
- [[错题队列]]：程序生成的原错题与复现日期，不手改机器区。

**教得怎么样**（这两页回答的是「流程本身有没有问题」）

- [[教学互动日志]]：卡顿、纠错、重复追问等摩擦的原始记录，由 `signal_log.py` 维护。
  成绩看训练记录，**摩擦看这里**。
- [[教学策略变更记录]]：每次流程改动的提案、结论、理由、回退办法，以及五条不可协商红线。

流程本身及每次修改原因见 [[教学流程复盘]]；待你确认的改进提案也在那一页。
排盘练习的结构化填写建议见 [[排盘练习批改界面-方案]]（当前待审批）。

## 每节课的两道闸门

```bash
python3 tools/retro.py --brief     # 开场：今天学什么、逾期复现、遗留摩擦、待确认提案
python3 tools/retro.py --close     # 收尾：跑十条规则，命中即起草提案，等你批准
```

agent 跳过任一道闸门都属于违反 `AGENTS.md` 第 2.6–2.7 节，直接指出来。

## 当前在读

```dataview
FROM "10-底本"

SORT 阶段 ASC
```

## 薄弱项（错过且未升级）

```dataview
TABLE 册, 阶段, mastery, error_count, weak_reason
FROM "10-底本" OR "20-概念卡"
WHERE error_count > 0 AND (mastery = "生" OR mastery = "会说")
SORT error_count DESC
```

## 本阶段待读

```dataview
TABLE 篇, 节, 类型, 页
FROM "10-底本"
WHERE 阶段 = 1 AND 状态 = "未读"
SORT 页 ASC
```

## 已通关

