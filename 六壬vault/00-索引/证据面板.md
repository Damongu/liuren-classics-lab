# 证据面板（Dataview）

> 需要安装社区插件 **Dataview**（Settings → Community plugins → Browse → 搜 Dataview → Install → Enable）。
> 装好后本页的代码块会自动渲染成表格。没装的话看到的是原始代码，不影响其他功能。

---

## 一、八部书总览（按证据等级排）

```dataview
TABLE WITHOUT ID
  file.link as 书,
  断代 as 断代,
  证据等级 as 证据,
  理据价值 as 理据,
  抄大全风险 as 污染风险,
  导入状态 as 状态
FROM #书卡
SORT 证据等级 ASC, 断代 ASC
```

**怎么用**：引任何一条原文前，先在这张表确认它属于哪一层。
基准层可以直接作硬证据；参照层只能佐证不能定规则；存疑待考层不能用来测年。

## 二、待核条目（录文还没回原刻核对）

```dataview
TABLE WITHOUT ID
  file.link as 条目,
  书 as 书,
  卷篇 as 卷篇,
  源文件 as 源文件
FROM #底本 AND #唐宋层
WHERE 待核 = true
SORT 书 ASC, file.name ASC
```

**怎么用**：这些条目可以读、可以先填矩阵，但**结论落地前必须核原刻**。
网络录文的脱字、误字率不低，尤其是数字（"三"↔"二"）和干支。

## 三、⛔ 高危：字句被后人改动过的条目

```dataview
TABLE WITHOUT ID
  file.link as 条目,
  书 as 书,
  卷篇 as 卷篇,
  污染类型 as 类型
FROM #底本
WHERE 污染 = true
SORT 书 ASC
```

**怎么用**：这些条目**不能作为《六壬大全》的独立证据**——它们本身可能就是据《大全》改的。
判定规则见 `[[互校污染规则-方法卡]]`。目前 20 条，**全部集中在《六壬心镜》**。

## 三′、⚠️ 混入后人注文的条目

```dataview
TABLE WITHOUT ID
  file.link as 条目,
  书 as 书,
  卷篇 as 卷篇
FROM #底本
WHERE 今注 = true AND 污染 != true
SORT 书 ASC, file.name ASC
```

**和上一节的区别（关键，别混）**：

| | 含义 | 证据力 | 怎么办 |
| :--- | :--- | :--- | :--- |
| `污染: true` | 字句**被改**过 | **打折／不可用** | 不能反校《大全》 |
| `今注: true` | 只是**加了注**，原文未动 | **不打折** | 引用时剥离注文即可 |

《六壬断案》212 条含缘生谛今注但 **0 条被改字** —— 它是可用的南宋占例，
不要因为"有注"就把它当污染排除掉。《六壬心镜》67 条含清人夹注（郑按／伟堂按等）。

## 三″、《武经总要》占候五卷的分层（别把旁证当硬证）

后集卷十六—二十是一整组官修占候，六壬只占其中 14 条。
其余遁甲／太乙／风角／占候入库是为了检索完整与术语互校，
**不能拿来定六壬规则**（唯风角篇例外，它是术语上游）。

```dataview
TABLE WITHOUT ID
  部 as 部,
  与六壬关系 as 关系,
  file.link as 条目
FROM #武经总要 AND #底本
SORT 部 ASC, 卷篇 ASC
```

**只取硬证**（本体规则＋术语共享两类）：

```dataview
TABLE WITHOUT ID file.link as 条目, 部 as 部, 与六壬关系 as 关系
FROM #底本
WHERE contains(与六壬关系, "本体规则") OR contains(与六壬关系, "术语共享")
SORT 部 ASC
```

导航见 [[00-分层索引-占候五卷]]。分层规则表在 `tools/build_vault.py` 的 `WJ_ROLE`。

## 四、开着的考据命题

```dataview
TABLE WITHOUT ID
  file.link as 考据卡,
  命题 as 命题,
  状态 as 状态,
  更新 as 最近更新
FROM #考据卡
WHERE 状态 != "已结项"
SORT 更新 DESC
```

**怎么用**：这是研究进度条。每张卡是一个可判真伪的命题，
状态流转：`待查` → `证据收集中` → `已结项` / `悬置（证据不足）`。

## 五、今天该复习什么（间隔重复）

```dataview
TABLE WITHOUT ID
  file.link as 卡,
  mastery as 掌握度,
  next_review as 到期
FROM #概念卡
WHERE next_review = null OR next_review <= date(today)
SORT next_review ASC
LIMIT 15
```

**怎么用**：概念卡的 frontmatter 里维护 `下次复习` 和 `掌握度`。
按 1 / 3 / 7 / 21 天推。答不出就回退一档。

## 备注：frontmatter 字段约定

为了让上面的查询有东西可查，各类文件的 frontmatter 保持一致：

**书卡**
```yaml
tags: [书卡]
书名: 太白阴经
断代: 唐·约759
证据等级: 一手
理据价值: 中
抄大全风险: 无
导入状态: 已导入
```

**底本条目**
```yaml
tags: [底本, 唐宋层]
书: 太白阴经
卷篇: 卷十-元女式
源编码: utf-8
待核: true
污染: false
```

**底本条目·分层字段**（目前只有《武经总要》用，以后导「一书内多层」的书照此办）
```yaml
部: 六壬          # 六壬 / 遁甲 / 太乙 / 风角 / 占候
与六壬关系: 本体规则   # 本体规则｜术语共享｜配套表｜同源三式｜兵占背景｜编纂背景
```
`本体规则` 与 `术语共享` 可作硬证；其余只作背景，不参与规则判定。

**考据卡**
```yaml
tags: [考据卡]
命题: 涉害俱深唐法取先干后支
状态: 证据收集中
更新: 2026-09-08
```

**概念卡**
```yaml
tags: [概念卡]
下次复习: 2026-09-11
掌握度: 2
```
