# Obsidian 插件验证清单

装完插件别猜有没有生效——**逐项做一遍下面的动作**，看到预期现象就算通。
本页本身就是测试用例：能看到下面第 1 项渲染出表格，Dataview 就是通的。

> 全部命令都在命令面板里执行：`Ctrl/Cmd + P`。

---

## 1. Dataview（必装，本库强依赖）

**验证**：看下面这块。

```dataview
TABLE WITHOUT ID 书 as 书, 证据等级 as 证据等级, 导入状态 as 状态
FROM #书卡
SORT 证据等级 ASC
```

- ✅ **通过**：上面是一张 **8 行**的表格（七部自动构建底本 + 一部待核残卷）。
- ❌ **没通**：你看到的是灰底代码块、写着 `TABLE WITHOUT ID ...` 的原文
  → 说明插件没启用。`Settings → Community plugins` 里确认 Dataview 是**开着**的（开关是蓝的）。

**为什么必装**：`证据面板`、`掌握度看板`、`唐宋层导入指南`、`武经总要分层索引`
这 4 个页面全靠它自动汇总。没它这些页面就是一堆代码块。

> ⚠️ Dataview 字段名写错时**不报错，只渲染空表**。所以字段一致性由
> `tools/selfcheck.py` 第 7 项机器兜住，别靠肉眼。

---

## 2. Obsidian Git（必装，你的免费同步方案）

**验证**（任一条成立即通）：

1. 左侧边栏出现 **Git 图标**（分支形状）。
2. 命令面板搜 `Git:` → 能列出 `Git: Open source control view`、
   `Git: Commit-and-sync` 等一串命令。
3. 打开 source control view → 因为仓库已有基线提交，此时应显示
   **当前分支名**且改动列表为空（或只列你刚改的文件）。

**实测一次**：随便改一个字并保存 → Git 面板里应立刻出现那个文件名。

- ⚠️ 只要命令能列出来、面板能打开，插件就是好的。
  `push` 失败是**远端还没配**，不是插件问题（配法见顶层 `README.md` 同步方案 A）。

---

## 3. Advanced Tables（建议）

**验证**：把光标放进下面这张表的任意单元格，按 `Tab`。

| 判别点 | 我的结论 | 待核 |
|---|---|---|
| 涉害取用 | | |
| 贵人表 | | |

- ✅ **通过**：光标跳到下一格，且表格竖线**自动对齐**；在最后一格按 `Tab` 会新增一行。
- ❌ **没通**：`Tab` 只是插了个制表符 / 光标没动。

（纯手感优化。不通不影响任何功能，`50-校读笔记/对校矩阵` 手写也能用。）

---

## 4. Templater（建议，但本库目前用不上）

⚠️ **先说清楚**：`20-概念卡/_模板-概念卡.md` 是**静态 Markdown**，
里面没有 `<% %>` 动态语法（我全库搜过，一处都没有）。
**所以你拿现有模板是验证不出 Templater 的**——插入了也只是原样复制。

**要验证就临时造一个**：

1. 新建笔记 `_test.md`，写一行：`<% tp.date.now("YYYY-MM-DD") %>`
2. `Settings → Templater → Template folder location` 设为该文件所在目录
3. 命令面板 → `Templater: Open Insert Template modal` → 选 `_test`
4. ✅ **通过**：插入后变成 **2026-09-08**（今天）；❌ 没通：原样是 `<% ... %>`
5. 验证完删掉 `_test.md`

**要不要用**：想让概念卡自动填建卡日期时再改造模板。现在不改也完全不影响。

---

## 5. Spaced Repetition（可选，**本库已有替代方案**）

⚠️ **重要**：本项目的复习不靠这个插件。
`tools/tutor.py` 已经实现了错题队列 + 1/3/7/21 天复现，
写进 `60-掌握度/训练记录.md` 和 `错题队列.md`，用的是概念卡里的
`next_review` / `mastery` / `error_count` 字段。
全库也没有 `#flashcard` 标记（我搜过）。**所以 SR 插件装了也没卡可复习。**

**非要验证**：新建临时笔记，写：

```
六壬的抽象盘总数是多少？::720 课（60 日干支 × 12 局）
#flashcard
```

命令面板 → `Spaced Repetition: Review flashcards` → ✅ 能弹出这张卡即生效。验证完删掉。

**建议**：两套复习机制别并行，会分裂。**优先用 `tutor.py`**——它能程序判分、
能调排盘器现算标准答案，插件做不到。SR 插件可以直接停用。

---

## 结论：真正必须通的只有 2 个

| 插件 | 必须通？ | 不通的后果 |
|---|---|---|
| Dataview | **是** | 4 个索引页变成代码块，看板全废 |
| Obsidian Git | **是** | 没有免费多端同步，也没有版本回滚 |
| Advanced Tables | 否 | 手写表格，纯麻烦一点 |
| Templater | 否 | 本库当前零依赖 |
| Spaced Repetition | 否 | 已被 `tutor.py` 替代，**建议停用** |
