# 交互训练·关卡表

阅读路线图管「读什么」，这张表管「练到没练到」。实际开课按阅读路线图的
“零基础执行序”；原书阶段只表示内容归属，不再直接决定初学顺序。

完整教学闭环与历次修改理由见 [[教学流程复盘]]；当前强弱项见 [[学习画像]]。

启动：

```bash
python3 tools/tutor.py            # 自动选当前该练的关
python3 tools/tutor.py -l 5 --n 20
python3 tools/tutor.py -l 1 --topic 遁干  # 学完遁干后只练遁干
python3 tools/tutor.py --review   # 错题复现（跨关卡，重问原题）
python3 tools/tutor.py --status   # 看进度条
```

`tutor.py` 是训练器，不承担首次教学。进入关卡时会先检查是否已经完成 agent 的四拍教学；
未学完就退出，不产生答题记录。关卡 1 包含寄宫、旬空、遁干三个概念，首次学习必须用
`--topic` 逐项练。每个专项固定 12 题，至少答对 11 题并完成专项白话复述；三项全部
通过后，才开放 12 题混合验收。

正式关卡前另有[[20-概念卡/式盘最小模型|第0课·式盘最小模型]]。它只建立术语与流程地图，
不由训练器判分，也不要求初学者提前计算天地盘或四课。

## 为什么判分是可信的

题目不是人写的，也不是模型编的：

1. **题库＝全集。** 六壬的抽象盘一共只有 **720 课**（60 日干支 × 12 局），
   `liuren.search.enumerate720()` 40 毫秒全枚举完。所以不存在「题目不够」的问题，
   反过来说也**没有超纲题**——任何一题都在这 720 之内。
2. **答案＝排盘器。** 标准答案由排盘器现算，不经过任何语言模型。
   模型会把三传算错，程序不会。
3. **讲解＝推导链。** 排盘器推课时会记下 `reason`（如「上克下凡 3 处：子、未、寅 →
   俱不比入涉害 → 深浅相等取临四孟 → 比用格改取比和之寅」），答完直接摊给你看。

**所以分工是：程序判分，agent 讲解。** 别让 agent 判分，也别让程序讲道理。

## 为什么必须分层抽题

720 课里九宗门的分布极不均：

| 课体 | 重审 | 元首 | 知一 | 涉害 | 遥克 | 伏吟 | 返吟 | 昴星 | 八专 | 别责 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| 课数 | 218 | 119 | 81 | 76 | 65 | 60 | 60 | 16 | 16 | **9** |

**别责只占 720 的 1.25%。** 纯随机抽 100 题，大概率一次都碰不到别责和昴星——
而这两门恰恰是最容易忘的。所以关卡 4 按课体**等概率**抽，不按自然频率。

这条也顺带回答了一个考据问题：别责在唐宋文献里有无踪迹，本来就存疑
（见 [[70-待查/待查清单]]）。它在全盘里如此边缘，未必是巧合。

## 「半对」是什么

底本自己有矛盾的地方，答另一说不算错，判 **◐ 半对**，并把两说的依据同时摊开。

最典型的是涉害比用格：

- 排盘器默认**开**比用格 —— 依据第六册涉害课「比用格」、第十一册第九十三法订讹
- 另一说**纯涉害** —— 依据第六册「见机格」例（庚子日戌时申将取午加庚）

同一部《六壬大全》里两处打架。你答哪个都不算错，但**必须知道它在打架**。
这类分歧排盘器会随盘输出 `divergences`，训练时一并显示。

## 训练与读书怎么配

```
读 → 四拍 → 练 → 错题四拍 → 迁移思考 → 白话复述 → 复现
```

1. 先完成第0课的盘面地图，再以《六壬大全》当前条目为主线，由 agent 按
   “解释 → 佐证 → 理解 → 质疑”完成一节教学。
2. 跑对应专项12题；关卡 1 首次练习用 `--topic` 指定刚学完的概念。
3. 错题自动进 [[60-掌握度/错题队列|错题队列]]，进度写入 [[60-掌握度/训练记录|训练记录]]。
4. **把错题贴给 Trae 里的 agent**，它针对断点重新走完整四拍：
   解释错在哪 → 唐宋文献怎么说 → 让你复述 → 反过来质疑这条规则。
5. 错题讲完后做迁移思考，再用自己的话向“小白 agent”重讲整个概念。
6. 练习达线且复述验收通过才最终过关；由 agent 记录，不由用户自行确认。
7. 隔 1／3／7／21 天 `--review`，**重问原题**（不是换新题，这一点很重要）。
   连对两次才出队。

判分和排期是程序的事，讲解和佐证是 agent 的事，读和想是你的事。

错题不按年代直接删除，而按原因分流。规则缺口进入 3～5 道变式训练；输入失误、有效的
另一口径、失效题和重复过量题退出活跃队列但保留归档。教学前基线题只复现一次：答对
即归档，仍错才转为正式薄弱项。可用：

```bash
python3 tools/tutor.py --wrong-list
python3 tools/tutor.py --weak 步骤遗漏
```

空间关系或取用路径仅靠文字难以看清时，应加入原书图或重绘示意图。原书图须标页码；
重绘图必须标“重绘示意，不作证据”。一张表能讲清的规则不额外加装饰图。
