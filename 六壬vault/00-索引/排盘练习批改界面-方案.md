# 排盘练习批改界面方案

## 结论

需要一个本地前端，但不是现在所有练习都搬进去：

- 单值题继续用 Terminal：寄宫、旬空、旬遁、贵人表等。
- 结构题使用浏览器界面：天地盘、四课、三传、涉害路径等。

前端只负责“好填写、看得清、记录完整”；答案仍由现有排盘器计算。

## 学习者怎么用

1. 程序给出日干支、占时、月将。
2. 学习者先填局数与天地盘；提交这一层后才判这一层。
3. 天地盘正确，再填四课。
4. 四课正确，再选克贼关系、九宗门和取用理由。
5. 最后填三传。
6. 程序标出**第一处错误步骤**，保存原答案，不直接把后面整盘答案全部摊开。
7. 错题进入 [[错题队列]]，完整推演供 agent 做四拍讲解。

## 第一版界面

### 题目栏

- 日干支
- 占时
- 月将
- 当前规则口径

### 天地盘填写

- 固定十二宫环形盘。
- 点击某宫，从十二支中选择该宫上神。
- 一键清空本层，但不显示答案。

### 四课填写

- 四列上下格，按一课至四课填写。
- 每一格使用支或干的选择控件，避免输入法和异体字造成误判。

### 取用填写

- 选择哪些课存在下克上或上克下。
- 选择九宗门。
- 涉害题再填写比较对象、涉害深浅和采用的口径。

### 三传填写

- 初传、中传、末传三个固定位置。
- 提交后由排盘器校验。

### 批改结果

- 显示第一处错误，而非只显示总分。
- 显示学习者原答案、程序答案和 `reason` 对应步骤。
- 有文献分歧时并列两说，不私自判掉其中一说。
- 提供“交给 agent 讲解”所需的结构化记录。

## 不做什么

- 不做断命、断事或自动吉凶判断。
- 不在提交前展示完整正确盘。
- 不让前端自行计算规则。
- 不把训练记录只存在浏览器缓存。
- 第一版不做账号、联网、云同步或复杂动画。

## 数据怎么流动

```text
排盘器生成题目和标准答案
        ↓
浏览器收集逐步推演
        ↓
程序按步骤比较，找到第一处差异
        ↓
_tutor_state.json 保存机器状态
错题队列.md 展示原错题
学习画像.md 由 agent 总结错误模式
```

## 为什么不让 agent 直接批改

三传和涉害存在长推导链及口径分歧，语言模型容易口算错。程序适合比较确定值，agent 适合
解释“为什么错”和“证据是否可靠”。前端只是让这两者之间的数据更完整。

## 验收标准

- 桌面和手机浏览器都能完整显示十二宫，不重叠。
- 不看答案可以独立完成天地盘、四课、取用和三传。
- 每次错误能定位到首个错误步骤。
- 同一输入与 CLI 排盘器结果完全一致。
- 错题、复现日期和训练统计与现有 Terminal 共用一份状态。
- 关闭前端后，Terminal 训练不受影响。
