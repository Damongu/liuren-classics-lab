# 排盘器怎么用（读书时随手查）

排盘器在 vault **外面**的 `liuren-paipan/`，不占 vault、不污染笔记。
在 Trae 的终端里跑，产物（课例卡）落回 `30-课例/`。

## 读到"某日某时某将"想看盘

```bash
python3 -m liuren pan --day 甲子 --shi 卯 --jiang 子
```

## 读到"某加某"想看盘（底本最常见写法）

```bash
python3 -m liuren pan --day 甲辰 --jia 戌加寅
python3 -m liuren pan --day 庚子 --jia 午加庚      # 地盘写日干也认，按寄宫落宫
```

## 想把这张盘变成作业卡

```bash
python3 -m liuren pan --day 甲子 --shi 卯 --jiang 子 --card \
  --question "四课里有几处上克下？为何取午发用？"
```

→ 自动写入 `30-课例/甲子日卯时子将-元首元首.md`，含盘、四课三传、口径依据、
「我的推演／批改／追问」三栏。**先自己排一遍再看卡**，别倒过来。

## 想找一张特定结构的盘来练手

```bash
python3 -m liuren find --keshi 涉害 --sub 察微 --kong y      # 涉害察微且三传带空亡
python3 -m liuren find --keshi 别责 --limit 20               # 别责全部 9 课
python3 -m liuren ke --day 甲子 --year 2026                  # 甲子日十二局全景
```

720 课＝60 日干支 × 12 局，穷尽全部结构。理论期用它挑结构，
真要落到真实时刻再加 `--realize 2 --place 成都`。

## 想看今天此刻的真盘

```bash
python3 -m liuren pan --time "2026-09-07 14:30" --place 成都
```

自动办三件事：地方平太阳时定时辰（成都比钟表慢约 64 分，会跨时辰）、
中气换将定月将、实际日出日入定昼夜取昼贵／夜贵。

## 看到盘上打「⚠ 分歧」

说明底本此处自相矛盾，引擎默认取了一说、另一说也列了出来，
对应条目在 [[待查清单]] 第二节。**这就是要你思考的地方**，不是 bug。

## 想验引擎有没有骗你

```bash
python3 tools/selfcheck.py                            # 拿底本"可数的自述"验算法
python3 tests/test_book_cases.py                      # 底本课例回归 18 项
python3 tools/validate_book.py --vault ../六壬vault    # 从全书自动抽课例反校
```
