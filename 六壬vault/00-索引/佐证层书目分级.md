# 佐证层书目分级（唐宋层入库清单）

**分级依据是"能不能当证据"，不是"有不有名"。**

配套规则：`50-校读笔记/互校污染规则-方法卡.md`（引用前必读）。

## 六、教学 / 理据层 — 与证据等级正交的第二个维度

证据等级回答"能不能引"，理据价值回答"读了能不能懂"。**两者互不相干，必须分别打分。**
唐宋层材料大多只给"怎么做"，不给"为什么这么做"；理据层补的正是后者。

| 书 | 理据价值 | 证据等级 | 怎么用 |
| :--- | :---: | :---: | :--- |
| 《壬归》卷一提纲例约 | ★★★ | 参照·待考 | **当提问器，不当答案源**：它列出该问什么，答案回唐宋层验 |
| 《大六壬心镜》格目 | ★★ | 二手（须句级过滤） | 体例框架可参，字句须查校记 |
| 《六壬大全》起例 | ★★ | 底本（待验） | 阅读主线，被检验对象 |

> ⚠️ 通则：**讲理据的书最容易把后世理解投射回去**。文字越顺、体系越自洽，越要过滤。
> 从理据层读到的任何"道理"，一律先记为待验命题，不得直接写进结论。

## 入库时每部书要打的标签

```yaml
证据等级: 一手 / 二手 / 参照 / 待考 / 不采信
理据价值: ★ / ★★ / ★★★
是否官修: 是 / 否
是否域外: 是 / 否
抄大全风险: 无 / 低 / 高
校记密度: 未查 / 低 / 高
可结项待查项: [ 列出本书能解决 70-待查 的哪几条 ]
```

最后一行是重点：**每部书入库前先声明它能解决哪条待查**，否则不入。
