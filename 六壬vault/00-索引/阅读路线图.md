# 阅读路线图（能力序，覆盖书序）

这本《六壬大全》的编排是**检索序**不是学习序：第一册「入手法」三页把九宗门口诀一次甩完，却一句解释都没有；全书最难的《心印赋》《囊括赋》《百炼金》排在第三四册；每个课例都直接写"甲子日卯时子将，午加酉为用"再配一张盘，作者从头假定读者会自己排盘。所以按册序读必然在第三站撞墙。

> 📐 **配套训练**：每个阶段的「通关里程碑」都有可判分的关卡，见 [[00-索引/交互训练-关卡表|交互训练·关卡表]]。
> 读完一节就跑 `python3 tools/tutor.py`，别只读不练——六壬前三关不牢，后面全是错的。

下面按**能力序**重排：阶段按里程碑通关，不按天数。每条笔记的 frontmatter 里有 `阶段`、`前置`、`mastery`、`状态` 四个字段，读到哪改到哪。

## 零基础执行序

《六壬大全》按会排盘的读者编写，不能把书目次序直接当教学次序。零基础课程先建立一张
不考核的“全盘地图”，再逐层组装；后文各阶段是阅读覆盖范围，实际开课以本表为准。

| 课序 | 内容 | 本课只解决什么 | 通关方式 |
| :---: | :--- | :--- | :--- |
| 0 | [[20-概念卡/式盘最小模型|式盘最小模型]] | 区分地盘、天盘神、四课、三传、十二天将 | 能指出各层先后，不要求计算 |
| 1A | [[20-概念卡/十干寄宫|十干寄宫]] | 把日干转换成地盘代理坐标 | 专项12题≥11＋白话复述 |
| 1B | 旬空 | 判断一日所属旬及两支空亡 | 专项12题≥11＋白话复述 |
| 1C | [[20-概念卡/旬遁干|旬遁干]] | 在一旬内给地支配置天干 | 专项12题≥11＋白话复述 |
| 2 | [[20-概念卡/天地盘|天地盘]] | 已知月将、占时，完成月将加时并读取上神 | 关卡2＋白话复述 |

| 8 | 课体、赋文、毕法与考据 | 读课、复盘、解释和辨析证据 | 按后续阶段里程碑 |

### 执行原则

1. 第0课只给地图，不提前教授后续算法。
2. 第1至6课使用题目直接给出的抽象日、时、将，先学盘法。
3. 第7课才加入中气换将和地方平太阳时，避免把历法输入与盘内算法混学。
4. 每次复述只检查本节已经明确讲过的内容；后续用途只能作为地图提示，不能成为验收题。
5. 已完成的训练成绩保留；课程改版不重置历史记录。
