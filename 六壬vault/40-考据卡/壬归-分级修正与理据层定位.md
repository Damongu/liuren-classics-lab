# 命题：《壬归》该放在哪一层

## 先认错：上一版分级是错的

`00-索引/佐证层书目分级.md` 初版把《壬归》列进第四层「不可用 / 托名 / 明清辑撰」，
这是**把两种完全不同的情况合并了**：

| 情况 | 例子 | 该怎么处理 |
| :--- | :--- | :--- |
| **托名** — 有明确迹象是伪托 | 题黄帝、题玄女、托名邵子的《六壬通神集》 | 不作证据 |
| **著录缺失** — 可能是真的，但证不了 | 《壬归》题宋郭子晟、《六壬一字诀玉连环》题宋徐次宾 | **存疑待考**，降级但不排除 |

飞书报告里对《壬归》的处置其实是对的（记作「未获可靠来源」、按待考处理），
是 vault 的分级卡把它写重了。**分级表缺一档「存疑待考」，这是方法漏洞，不是单书误判。**

## 这书到底是什么

- 全名 **《新编日用涓吉大六壬总归》**，通称《壬归》，题 **宋·郭子晟** 撰（一作辑录）。
- **七卷本**：卷一提纲例约、卷二壬占易简例约、卷三谋望门、卷四婚姻门、卷五农事门、
  卷六出行门、卷七三才门。
- 另有上下册本（题《新编日用涓吉大六壬总归》，卷一作「入门须知」：月将、占时、日辰、四课…），
  与七卷本卷次结构不同，**两系关系待考**。
- 今人校本：林三玄校正本（子部珍本备要 035）、郑同校《大六壬总归》（三式汇刊）。
  书商另有「明抄全本」之称，**未核实物与藏地**。
- **《四库全书》《古今图书集成》《四库未收书》皆未收**，一路以民间抄本流传。

宋撰身份目前只有两样东西支持：**书内题署**，和**今人序说**。没有宋元书目著录，
没有藏书机构编目，没有可核的早期刻本。与《毕法赋》「宋撰依据只有一篇自序」是同一档处境。

💭 猜测（一条可查的线索）：书名格式「新编·日用·涓吉」与《遁甲日用涓吉奇门五总龟》同一命名传统，
属宋元明**日用类书**系列的命名法。若能证明这是同一书坊系列，就能把成书区间从"题宋"
收窄到具体的日用类书流行期——这比争论郭子晟是谁更有希望。

## 双轨定位：证据等级低，理据价值高

这两件事必须分开打分，混在一起才会出现"要不要"的困惑。

### 作证据用 → 参照层，打折

不能用它证明任何规则起于宋。凡它与唐宋层（元女式、《占事略决》、官修本）冲突，以唐宋层为准；
凡只有它这么说，标待考。

### 作理解用 → 第一梯队，优先读

卷一提纲例约把该问的问题列了出来：**观四课之加临、察用神之生克、传始终、贵神吉凶、判八煞**。
这是六壬文献里少见的**结构性总纲**——唐宋层材料多是条文和口诀，只给"怎么做"，不给"为什么这么做"；
《壬归》给的正是后者，而且文字近白话，零基础可直接读。

对「九宗门为什么是九宗门」这类问题，它是目前最好的中文入口之一。

## 使用规则：当提问器，不当答案源

这是本卡的操作结论。

```
《壬归》 → 生成"该问什么"的问题清单
唐宋层   → 回答这些问题
《大全》  → 被这些问题检验
```

具体做法：读《壬归》某条理据（例如它如何解释涉害取用的道理），**不要**记作"六壬如此"，
而是记成一条待验命题，写进 `40-考据卡`，再拿元女式与官修本去校。
它讲得越顺、越自洽，越要警惕——**讲理据的书最容易把后世的理解投射回去**，
清人讲唐法讲得头头是道，恰恰是最需要过滤的一类文本。

## 当前结论

- 分级从「不可用」**改为参照层 + 存疑待考**，并在分级表新增「教学 / 理据层」这一正交维度。
- 阅读优先级：**卷一提纲例约可以早读**（与《六壬大全》起例并行，帮助建立结构感）；
  卷三至卷七的分门占法属应用层，理论期不必碰。
- 同类需要一起改判的：《六壬一字诀玉连环》（题宋徐次宾，人名两写未统一）——
  同样从「不可用」移入「存疑待考」。

5. **它的规则与元女式冲突吗**？特别是三处：涉害俱深取谁、贵人表用哪一套、昴星取用。
   若《壬归》站在明本一侧（孟仲季、甲戊庚），则它的年代很可能晚于题署；
   若站在唐本一侧（先干后支、庚辛同组），题宋的可信度就上升。**这是最有判别力的一次比对，
   也是眼下最容易做的。**
