# 九宗门为什么是九：一次北宋的结构重组

## 这张卡回应的是最初那个问题

> 「九宗门为什么是九宗门，不同起四课三传的方式是否会有不同的用法，
> 以及九宗门之间有什么异同？」

现在有了第一条可查的线索：**"九"这个数目在十世纪和北宋之后，装的不是同一批东西。**

## 两份九门清单

| # | 十世纪《占事略决》「课用九法」 | 后世九宗门 |
| :--- | :--- | :--- |
| 1 | 贼克（下克上／上克下） | 贼克 |
| 2 | 比用 | 比用 |
| 3 | 涉害（加孟为深／加仲为半／加季为浅） | 涉害 |
| 4 | **涉害俱等取先举**（日为先辰为后，阳为先阴为后） | 遥克 |
| 5 | 遥克 | 昴星 |
| 6 | 昴星 | **别责** |
| 7 | 伏吟 | 八专 |
| 8 | 反吟 | 伏吟 |
| 9 | 八专（原文称「五柔日」） | 反吟 |

出处：[[占事略决-第2章 课用九法]]，篇题原文即作「课用九法」。

## 两处差异，互相咬合

### 差异一：涉害在十世纪是两门，后世并成一门

《占事略决》第三法定深浅（孟仲季），第四法裁平局（先举者）——
**分列为两个独立法门**。后世把这两步合并为"涉害"一门。

⚠️ 注意：这两步**本来就是两个环节**，不是两种说法。
把它们当成对立二说是概念错误，详见 [[对校矩阵-五个判别点]] 结论 B。

### 差异二：别责在十世纪不存在

| 本 | 断代 | 有别责？ | 原文 |
| :--- | :--- | :---: | :--- |
| 《太白阴经》 | 唐·759 | **无** | 卷十全文已入库，处理「四课不相见」只给八专 |
| 《占事略决》 | 10c 末 | **无** | 九法中无此门 |
| 《景祐神定经》 | 宋·1034 | **有** | 「乃阴阳不备之时，当以别责为用。**别责之课，其数有九**。刚日有三，谓戊辰、戊午、丙辰……柔日有六」 |
| 《武经总要》 | 宋·1044 | **有** | 昴星例末：「若昴星不备为无四课当别摘一神为用，刚日以**干合**上神，柔日以**支合**上神为用」 |

**唐、十世纪均无；北宋两部官修书均有。**

## 推论

> 后世九宗门的"九"，是在北宋**合并涉害二门、腾出一格给新入的别责**之后形成的。
> 数目守恒为九，但**成分已经换过一味**。

如果成立，两个后果：

1. **"九"不是一个自古如此的神圣数目**，而是一次结构重组的结果。
   这就解释了为什么历代对"九"的解说总有龃龉 —— 它本来就被重排过。
2. **别责可以当断代锚点**：文本中出现别责 → 不早于北宋。
   这比大多数术语性锚点都硬，因为别责是个完整法门，不是一个词。

## 为什么现在还不能定论

三个缺口：

| 缺口 | 为什么要紧 |
| :--- | :--- |
| **《占事略决》第四法是否原书就独立成条** | 若是后人整理时分出来的，则"十世纪的九"这份清单本身不可靠，整个对照失效 |
| **唐本有无"九法"之称** | 《太白阴经》把诸法一气写在「推四课法」里，**未称九**。若唐本确实不称九，则"九"这个数目本身就是十世纪的构造，而非唐制 —— 那问题就变成"十世纪为什么凑成九" |
| **别责在《景祐》之前的踪迹** | 景祐（1034）已说「其数有九」，语气是**在陈述既有定数**，不像新创。说明别责入门更早，须找上限。最该查的是《武经总要》大量引用的《玉门经》《金匮经》残文 |

## 一个可做的旁证

《景祐》说别责「其数有九」——**别责本身也是九课**（刚日三：戊辰、戊午、丙辰；柔日六）。
本 vault 的排盘器已穷举验证过这一点：

> 别责课共 9 课｜戊午戊辰丙辰丁酉辛酉各一、辛丑辛未各二｜**9，日次完全一致** ✅

见 [[待查清单]] 第三节。这说明《景祐》的别责定义**是可穷举自证的**，不是虚设。
一个能自证的完整法门，不太可能是一时增设 —— 侧面支持别责在景祐前已成熟。
