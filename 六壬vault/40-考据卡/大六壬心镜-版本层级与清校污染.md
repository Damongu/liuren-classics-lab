# 命题：今本《大六壬心镜》八卷中，哪些文字可以当唐证用

## 结论先行（不要问"几卷是唐人写的"）

这个问题的提法本身是错的。**清人的掺入不是按卷发生的，是按句、按条、按校记发生的。**

- 若问"框架"：**八卷都可以视为旧观**。徐道符自序自道「计备格一百八十一篇，分为八卷」，
  清辑校本校按亦明言「其卷数篇次，悉依旧观」。所以八卷这个骨架本身不是清人新分的。
- 若问"文本"：**没有任何一卷是干净的**。哪一卷都可能有清人据他本改过的字句，而且改动处
  往往有校记自我暴露。
- 正确的提问方式：**这一句被清人动过没有？**

所以本卡不给"卷数配比"，只给一条判定规则和一张待建的位置表。

## 正方证据（八卷框架属旧）

| 证据 | 内容 | 定位 | 用途 |
| :--- | :--- | :--- | :--- |
| 徐道符自序 | 「计备格一百八十一篇，分为八卷」 | 今本卷首自序 | 篇数与卷数是作者自道，可作原始体量 |
| 清辑校本校按 | 「其卷数篇次，悉依旧观」 | 今本校按 | 清人自称未重分卷 |
| 校按对卷数的解释 | 古书手卷形态"书少而卷多"，《通志》《浙江省书目》作三卷系后来并卷 | 同上 | 解释八卷 / 三卷之异，不构成改动 |
| 钱曾《读书敏求记》 | 徐道符《心镜》→ 建炎中邵彦和《口鉴》→ 宝庆改元凌福之 | 正规书目 | 证明《心镜》在宋代确为主流传承源头 |

## 反方证据（文本层已被清人回改）

| 证据 | 内容 | 定位 | 危害 |
| :--- | :--- | :--- | :--- |

## 断代判定

三层结构，必须分开对待：

```
第一层  唐（徐道符原书）        —— 八卷 / 181 篇的体例、格目名称、术语框架
第二层  宋（邵彦和—凌福之传承） —— 《心镜》在宋代被继承、扩写、被《大全》吸收
第三层  清（程树勋 / 程伟堂手录辑校）—— 逐句校改、据《大全》回改、从《通神集》补入
```

引用规则：

1. **格目名称、篇次结构、八卷体例** → 可作唐层参考（等级：二手偏可信）。
2. **具体断辞、课例、数字** → 默认降为清层，除非有唐宋他证。
3. **凡该句有校记明示"据《大全》改""据某本改正"** → **禁止**用来反校《六壬大全》（见下）。

## 致命项：循环污染

这是本卡最重要的一条，会直接改变互校流程。

```
《六壬大全》（明）——全收《六壬心镜要》────┐
                                            │  同一批文字来回流动
今本《大六壬心镜》（清）——据《大全》改正 ──┘
```

后果：拿今本《心镜》去校《六壬大全》时，如果落点正好是清人据《大全》改过的地方，
**你校出来的"吻合"是自己造的，不是独立证据**。这类"吻合"必须判为无效证据，
在校读笔记里标 `⛔ 循环`。

操作要求见 `50-校读笔记/互校污染规则-方法卡.md`。

## 当前结论

- "八卷中多少卷是唐人写的" → 无法按卷回答；框架八卷皆旧，文本无一卷干净。
- 今本《大六壬心镜》定位：**辑校二手本**。可用于提示唐宋层的存在与体例，
  **不可单独作为宋制硬据**。
- 在佐证层分级中，《六壬心镜 / 心镜要》列**基准层但需句级过滤**，不是无条件基准。

## 未决问题（魔鬼代言人留下的）

1. **「者符」还是「乾符」？** 必须回程氏家刻本原书影核字。若为"乾符"，徐道符晚至晚唐，
   那么《心镜》与唐前期式法之间还隔一层，唐证力度进一步下降。
2. **校记总量有多大？** 需机械筛查今本八卷所有"据…改""据…改正""疑""脱"字样，
   建 `污染位置表`。在此表建成前，任何《心镜》→《大全》的互校结论都只能记为"暂定"。
3. **从《通神集》集出的那一册具体是哪部分？** 程树勋自己都不知道有无误摘他文，
   这一册应整体降级为参照层。
4. **四库著录《六壬心镜要》与今本八卷《心镜》的关系** 是节本、异名，还是不同传本？
   需核四库原条。
5. 是否存在**未经清校的写本系统**（如吕汉枫写本的其他抄支）可作对照？
