# 命题：《六壬心镜》到底几卷

## 结论先行

**卷数不唯一，问卷数问不出结果；要问篇数。**

三种形态并存，都不是错的：

| 形态 | 出处类型 | 说明 |
| :--- | :--- | :--- |
| **八卷** | 徐道符自序、清程氏辑校本 | 自序「计备格一百八十一篇，分为八卷」；清校按「其卷数篇次，悉依旧观」 |
| **三卷 + 后集一卷** | 部分著录 | 后集当为附出杂占部分 |
| **三卷** | 《通志》《浙江省书目》等 | 清校按解释：古书手卷形态"书少而卷多"，三卷系后来**并卷**所致 |

## 稳定不变量：181 篇

卷数会因为装帧形态（手卷 → 册本）而伸缩，**篇数不会**。

> 「计备格一百八十一篇」——这是作者自道的体量，穿过唐、宋、清三层都没变。

所以在本 vault 里：

- **对校单位取"篇"，不取"卷"。**
- 引用《心镜》时写 `《心镜》第 N 篇`，卷次只作辅助定位。
- 见到"三卷本"与"八卷本"不必当成两部书，先按 181 篇对齐。

## 断代判定

```
唐  徐道符原书 = 181 篇 / 8 卷（手卷）
宋  被吸收进主流传承（邵彦和—凌福之），并被明《六壬大全》收作《心镜要》
清  程树勋手录辑校，篇次卷数依旧观，但文字已经清校
```

四库著录之《六壬心镜要》与八卷本《心镜》的关系（节本？异名？异传本？）**尚未核实**，
是本卡最大缺口。

## 当前结论

- 回答"几卷"：**通常按八卷说**（作者自序 + 清辑校本一致），但要同时知道三卷本的来由。
- 真正该锚定的是 **181 篇**。
- 卷数问题与文本可信度问题是**两件事**：卷数依旧观 ≠ 文字未被改。
  文字污染见 `40-考据卡/大六壬心镜-版本层级与清校污染.md`。
