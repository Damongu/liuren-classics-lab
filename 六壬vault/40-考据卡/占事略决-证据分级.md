# 命题：《占事略决》是日本人写的，还能不能当中国六壬的证据

## 结论先行

能，而且是**目前最硬的早期快照之一**。

它既不是"日本原创的另一套术"，也不是"安倍抄的一本中国书"，而是第三种东西：

> **日本人用汉文，把当时手上的中国六壬法压缩成的一份提要。**

三点区分清楚：

| 常见误解 | 实际 |
| :--- | :--- |
| 日本人写的 → 是日本术数 | 术法本体是中国六壬。四课三传的起法与中国系统一致，不是另一套 |
| 安倍晴明抄的 → 是抄本 | 不是逐字抄某一部书，是**编成的纲要**，书末跋自道「粗抽六壬之意而已」 |
| 域外的 → 证据力弱 | 恰恰相反：**域外传本没有参与中国明清那一轮改写**，所以干净 |

## 正方证据（可作早期证据）

| 证据 | 内容 | 用途 |
| :--- | :--- | :--- |
| 作者与年代 | 安倍晴明（约 921–1005）撰，一卷，汉文 | 成书在十世纪末，**早于《六壬大全》约六百年**，也早于现存宋刻六壬书 |
| 自述性质 | 书末跋「粗抽六壬之意而已」 | 作者自道是提要、抽要，不是创制 |
| 奥书数字 | 「凡六壬占七百廿也」 | 七百二十课的总数在十世纪末已成定说，与底本自述吻合 → 可作硬证 |
| 术法一致性 | 四课三传起法与中国六壬同 | 说明所据是成熟的中国式法，不是本土改造 |
| 日方定位 | 小坂真二《安倍晴明撰『占事略決』と陰陽道》（汲古書院 2004）视为概说书 / 入门纲要 | 提要性质是学界共识，不是我们的推测 |
| 实占互证 | 《本朝世纪》仁平元年（1151）六月廿七日伊势神宫怪异占文，可与本书手顺对读 | 证明这套手顺被真实施用，不是纸面理论 |

## 反方证据（限制条件，必须写清）

| 限制 | 说明 | 影响 |
| :--- | :--- | :--- |
| 是提要不是全书 | 「粗抽」二字自道体量有限 | **沉默不构成否证**：书中没写的，不能推论"中国当时也没有" |
| 有域外遴选 | 编者按日本阴阳道实用需要取舍 | 详略比例不能当作中国原书的详略比例 |
| 传抄层 | 今存者为后世抄本（如京大藏本 RB00008037），非晴明手稿 | 字句仍需版本对校 |
| 不是宋书 | 严格说是**唐末五代式法的域外定格**，早于宋 | 用于"宋制还原"时定位是"宋前底线"，不是宋制本身 |

## 断代判定

```
唐（中国式法）→ 十世纪末日本编成《占事略决》→ 后世日本抄本
                        ↑
              这一格没有被明清中国改写污染
```

因此它的功能不是"补充细节"，而是**卡下限**：

> 凡《占事略决》已有之法 → 该法不晚于十世纪末，明清不能算作创制。
> 凡《占事略决》所无之法 → 只能记"未见"，不能判"无"。

## 当前结论

- 在佐证层分级中列**基准层**，与《景祐六壬神定经》《武经总要·六壬占法》同级，
  且在"未被明清改写"这一点上比今本《心镜》**更干净**。
- 与《大六壬心镜》互补：《心镜》体量大但被清校污染，《占事略决》体量小但层次干净。
  两者交集处的规则，可作最高等级的早期共识。
