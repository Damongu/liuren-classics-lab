# 命题：《太白阴经》卷十「元女式」是唐代六壬的完整程序快照

## 书的身份先钉住

- 《太白阴经》＝**《神机制敌太白阴经》**，同一部书，唐李筌撰，又名《太白阴符》。
- **卷数有两系**：唐、宋两志皆作十卷；《四库全书》收范氏天一阁藏本**止八卷**，馆臣已疑非完书。
  今另有清抄十卷本（美国加州大学柏克莱分校东亚馆藏）、《墨海金壶》本、平津馆影宋抄本。
- **「元女式」在十卷本卷十「杂式」之首**，同卷另有察情胜败、主客向背、推神煞门户、龟卜、山冈营垒。
- **引用格式统一写作**：`《太白阴经》十卷本·卷十·杂式·元女式`。不要只写"卷十"——
  八卷本系统卷次不同，容易对不上。

## 为什么这一篇比想象的重要

它不是"提到六壬"，而是**把起课全流程写完了**：开篇即自道「元女式者，一名六壬式」，
随后依次给出推月将、推四维、推三十六禽、**推四课法**（含贼克、比用、涉害、遥克、昴星、
伏吟反吟、八专）、**推天乙所理法**（贵人表）、推十二神将法，再接兵占诸法。

也就是说：**九宗门的主干在唐代已经成型**，不是宋人构建、更不是明人整理的产物。

## 五条可以直接结账的对照

| 项 | 元女式（唐） | 《六壬大全》（明） | 判定 |
| :--- | :--- | :--- | :--- |
| **起课总纲** | 「常以月将加正时，视干日、支辰、阴阳，以为四课」 | 同 | ✅ 唐宋明一贯，无争议 |
| **月将配法** | 「登明正月将加在亥水神」 | 同 | ✅ 明本用的是《太白阴经》一系，不是《神定经》的月建配将 |
| **涉害俱深怎么办** | 「涉害深者为用，**涉害俱深，以先干後支为用**」 | 订讹层取临孟＝见机；课经层甲午例「刚日以日上先见神为用…名曰缀瑕」 | ⚠️ **重量级**：唐法是"先干后支"，即课经层的**缀瑕**一路；**孟仲季取用未见于唐本** |
| **昴星以酉为枢** | 「刚干，视酉上所得神为用；柔干，视从魁所临神为用」（从魁＝酉） | 同 | ✅ 唐已如此，"酉为枢"不是宋人新设 |
| **八专** | 「四课不相见。刚干，从干上阳神顺数；柔干，从支上阴神逆数」 | 同（顺数三 / 逆数三） | ✅ 一贯 |

### 涉害那条要单独说

`70-待查` 里长期悬着两条：**孟仲季按宫还是按上神**、**深浅相等叫见机还是缀瑕**。
元女式给出的答案是：唐法在深浅相等时**根本不走孟仲季**，直接「先干后支」。

这把问题的性质换了。原来以为是"底本前后不一"，现在更像是**两个时代叠在一起**：

```
唐  深浅相等 → 先干后支（＝缀瑕）
明  深浅相等 → 取临孟 / 无孟取仲（＝见机），另存缀瑕于课经层
```

📌 待确认：孟仲季说最早出现在哪一部书。若在《景祐六壬神定经》或《心镜》能找到，
则属唐末至宋的增设；若最早只见于明本，则见机一门的断代要整体后移。
在此之前，排盘器的 `--shehai-class` / 见机缀瑕分歧**不要合并，两说都要留**。

## 贵人表：唐本是第三套，不是通行表

「天乙者，贵人也。家在丑」——本家在丑与通行一致。但十干分组只有五组：

| 日干 | 旦（昼） | 暮（夜） |
| :--- | :--- | :--- |
| 甲戊 | 大吉 丑 | 小吉 未 |
| 乙己 | 神后 子 | 传送 申 |
| 丙丁 | 登明 亥 | 从魁 酉 |
| **庚辛** | 胜光 **午** | 功曹 **寅** |
| 壬癸 | 太乙 巳 | 太冲 卯 |

对比通行歌诀「甲戊**庚**牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸兔蛇藏，**六辛逢马虎**」：

- 乙己、丙丁、壬癸三组**完全吻合**。
- **庚的归属不同**：唐本庚与辛同组（午 / 寅），通行本庚归"甲戊庚"（丑 / 未），只有辛作马虎。

所以现在手上有**三套贵人表**：元女式（唐）、《六壬大全》「先天贵神」歌、通行「甲戊庚」表。
排盘器目前默认通行表、`--guiren book` 切底本表，**应再加一档 `taibai`**，
把唐本庚的异读保留为可切项，不要静默合并。

## 昼夜分界：唐法给的是天象，不是固定时辰

「常以**星没为旦，星出为暮**」——以晨昏见星为界，属实测天象一路，
与排盘器默认的"实际日出日入"同一路数，而非固定卯申界。

这条支持现有默认口径。固定卯申界应视为后起的简化，`--daynight fixed` 保留为可切即可。

## 十二天将：本篇有脱文，别拿它当完整表

「天乙理十一将，前尽于五，後尽于六」——前五：螣蛇、朱雀、六合、勾陈、青龙；
后列举天后（后一）、太阴（后二）、太常（**后四**）、白虎（后五）、天空（后六）。

**"后三"整条缺失**，按位次应为玄武。这是转录或原刻的脱文，不能据此说唐本无玄武。
用此篇校天将顺序时，只用"前五 / 后六"的框架，不要用具体名目清单。

## 术语陷阱：这里的「天乙」有两个意思

同一篇里，巳的月将名写作「天乙七月将加在巳火神」，而贵人也叫「天乙者，贵人也」；
后文「壬癸之日旦理**太乙**」又把巳称太乙。

引用时必须区分**巳的将名（太乙）**与**贵人（天乙 / 天一）**，否则会读出假冲突。
这也是明清本把贵人统称"贵人"而少用"天乙"的原因之一。

## 当前结论

- 《太白阴经》在佐证层的位置**上调**：不只是"提到六壬的唐代兵书"，
  而是**唐代六壬起课程序的完整快照**，与《占事略决》同为基准层最干净的两件。
  优先级从 ★★ 升为 **★★★**。
- 它的独特价值：**成书早、非术家传承、且未参与明清那一轮改写**。
  作者是兵家而非壬家，取舍偏实用，但正因如此没有门派修饰。
- 与《占事略决》互补：两者都在十世纪前后、彼此独立、地域隔绝。
  **两者交集处的规则可判为唐代通行之法，举证责任转到明本一侧。**
