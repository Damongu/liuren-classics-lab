# 风角篇：《景祐》引书的本体，就在《武经总要》里

## 一句话结论

《景祐六壬神定经·释六情第十一》两次明写「**《风角》曰**」来解释六情与刑，
而《武经总要》后集卷十七「占候二」正有一篇 **风角**，其六情段与《景祐》
**几乎逐句对应**。两者不是「相似」，是**同一段材料的两个抄本**。

这条推翻了原先的分层判断：卷十七风角篇不是「兵占背景」，
而是**六壬术语（六情／德／刑／墓）的上游本文**，属可直接引用的一手材料。

## 一、对读：六情十二支配属

《武经总要》卷十七风角末段与《景祐》释六情第十一，同用**翼奉—孟康**一套说法。

| 情 | 支 | 《景祐》释六情（1034–38） | 《武经总要》卷十七风角（1044） | 判 |
| :--- | :--- | :--- | :--- | :--- |
| 好·贪狼 | 申子 | 北方水，水生于申，盛于子 | 北方水，水生于申，盛于子 | 全同 |
| 怒·阴贼 | 亥卯 | **东方木**，木生于亥…以阴贼**害土** | **东方水**，木生于亥…以隂贼气**害木** | 武经两处讹 |
| 恶·廉正 | 寅午 | 南方火，火生于寅，盛于午 | 南方火，火生于寅，盛于午 | 全同 |
| 喜·宽大 | 巳酉 | 西方金，金**生于巳**，盛于酉 | 西方金，金**生于丑**，盛于酉 | 武经讹 |
| 乐·奸邪 | 辰未 | **上方谓东方与西方也** | **上方之情乐，东与北也** | **景祐讹** |
| 哀·公正 | 戌丑 | **下方谓南方与北方也** | **下方，南与西也** | **景祐讹** |

### 谁对谁错，可以纯靠内部逻辑判定，不需要第三本书

- **上方＝东与北**：上方主辰、未；辰是「水穷」（水属北），未是「木穷」（木属东）。
  故上方只能是**东与北**。《景祐》写「东方与西方」，与它自己下一句的
  「辰穷水也，未穷木也」直接矛盾 → **《武经总要》保存了正字**。
- **下方＝南与西**：下方主戌、丑；戌「窃火」（南），丑「窃金」（西）。
  《景祐》写「南方与北方」同样自相矛盾 → **《武经总要》正**。
- **金生于巳**：六情把金系在**巳酉**，且风角自己的五墓条说「金墓在丑」。
  丑是金之墓，不可能又是金之生 → **《景祐》正，《武经总要》讹**。
- **阴贼害土**：木贯地而出，克土；「害木」讲不通 → **《景祐》正**。

**这就是互校的实际收益**：两部官修书各有讹字，互相纠正后得到的文本，
比任何单本都可靠。这也是为什么不能只导六壬那七千字。

## 二、连带确认：一条久悬的引书

《景祐》通篇引书甚多（《灵辖经》《玉门经》《金匮经》《神枢经》…），
其中《风角》一向被当作已亡的汉唐风角类书。现在可以说：

> **《武经总要》卷十七风角篇，是《景祐》所引《风角》系统现存最完整的宋代载体。**

两书同出仁宗朝、同为敕撰、相隔不到十年，见 `[[杨维德-两部北宋官修书的同一编者]]`。

## 三、风角篇顺带给出的六壬术语定义（1044 官修口径）

这些是六壬断法天天用、但《六壬大全》从不定义的基础表。
原文见 [[武经总要-后集卷十七 占候二 风角]]。

| 术语 | 风角原文 | 与六壬的关系 |
| :--- | :--- | :--- |
| 德 | 阳德自处，甲丙戊庚壬…假如甲日甲德在甲 | 六壬「日德」 |
| 德合 | 阴德在阳：乙德在庚、丁德在壬、己德在甲、辛德在丙、癸德在戊 | 六壬「德合」 |
| 三刑 | 寅刑巳、巳刑申、申刑寅／未刑丑、丑刑戌、戌刑未／子刑卯、卯刑子 | 伏吟三传要用，见 `[[自刑与三刑-两套刑法的合流]]` |
| 四杀 | 寅午戌杀在丑／亥卯未杀在戌／申子辰杀在未／巳酉丑杀在**戌** | 末字疑讹，当作「辰」，见下 |
| 五墓 | 木墓在未、火墓在戌、水土墓在辰、金墓在丑 | 六壬墓神 |
| 纳音 | 一言土、三言火、五言水、七言金、九言木；子午庚、丑未辛、寅申戊、卯酉巳、辰戌丙、己亥子 | 大挠五音配五行 |
| 主客 | 日辰纳音五行为客，时下十二辰与风来方为主人 | 与六壬兵占「主客」同构 |

### 「巳酉丑杀在戌」是讹字——一个可教学的样本

四杀是三合局对应的一支。前三条 寅午戌→丑、亥卯未→戌、申子辰→未
都是**三合局墓支的下一支**（丑、戌、未）；巳酉丑局理当配 **辰**。
原文两条都作「戌」，属抄手涉上而误。

> **方法论**：官修书也有硬讹字。凡遇一表之中出现**重复项**（这里「戌」出现两次）
> 而其余项两两不同，先怀疑抄讹，再查他本，不要急着解释成「另一说」。
