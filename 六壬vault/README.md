## 三条处理规则

1. **正文与盘分离**：盘（原书矢量线框内的文字）不进正文，按页原样留在「盘」区；需要结构化重排时向 agent 点单。
2. **今注剥离**：`（达注：…）`全部摘走。总钤那 20 页据无咎自述为壬友提供、今人补入，标为「表钤（今人补入）」，不作排盘答案。
3. **能力序覆盖书序**：`阶段` 字段是读的顺序，册序只是原书的检索顺序。先看 `00-索引/阅读路线图`。

### 两个标记，别混

每条底本条目的 frontmatter 里可能有：

| 标记 | 含义 | 证据力 |
| :--- | :--- | :--- |
| `污染: true` | 字句**被后人改动**过 | **打折／不可作《大全》的独立证据** |
| `今注: true` | 只是**混入后人注文**，原文未动 | **不打折**，引用时剥离注文即可 |
