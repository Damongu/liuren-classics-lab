# 90-禄命辅助/

## 目录用途

本目录收「宋壬与禄命一脉相承的辅助卡」：宋壬断辞里频繁出现、
却又与禄命家法共享同一套语义的概念（本命、行年、年命上神、
禄、马、贵人、天乙、驿马 等）。它们既是六壬断案的现役术语，
也是禄命法的家常词汇；放在同一处便于查检共享概念的界说、
在断辞中的用法、宋本硬证以及易混淆点。

本目录**不是术语对照表**，也不承担"把禄命理据搬进六壬"的角色。
凡宋本硬证不足的推断，一律留在四段模板的 `TODO` 里等待子项目 D
补齐后升级 `状态`；不做类比反推，不塞私货。

## 四段模板

每张卡固定四段：

1. **一、界说** — 该概念在禄命法与六壬中的一致含义（一句话）
2. **二、在断辞中的用法** — 举 1–2 个宋本断辞用例，标 anchor_id
3. **三、宋本硬证** — 列 2 处宋本原文出处
4. **四、易混淆点** — 与他书或近义概念的区别

每段带 `<!-- TODO(D-N): ... -->` 占位，说明子项目 D 会填内容。

## Frontmatter · `状态` 字段

`状态` 取三档：

| 值 | 含义 | 检查器（`tools/check_v3_frontmatter.py`）行为 |
| :--- | :--- | :--- |
| `stub` | 骨架，仅有模板占位 | 所有 v3 字段检查降级为 info（不判 fail） |
| `draft` | 子项目 D 正在填 | 与其他底本条目同规约，缺字段判 error/warn |
| `done` | 已定稿 | 与其他底本条目同规约 |

新建 seed 与经 `tools/add_lulu_stub.py` 增补的卡默认 `状态: stub`，
不影响 `一键部署.sh --check` 全绿。

## 与主线 `20-概念卡/` 的区别

- `20-概念卡/`：六壬本体全部概念的规范化条目（月将、天将、类神、
  神煞、四课三传、遁干、贵人起法 等）。凡六壬内部说得清楚、
  不需要跨家理据的，都在那里。
- `90-禄命辅助/`：只收禄命与宋壬**共享**的概念。这些概念在两家
  都出现，且在宋壬断辞里的用法与禄命家法一致。它们是理解宋壬
  断辞的辅助入口，不是六壬本体的核心。

若某个概念在宋壬内部已能自洽解释（如「月将」），归 `20-概念卡/`；
若必须借禄命家法才能读懂断辞用法（如「本命」「行年」），归本目录。

## 增补新卡

新增一张禄命辅助卡：

```bash
python3 tools/add_lulu_stub.py <概念名>
python3 tools/add_lulu_stub.py 天医
python3 tools/add_lulu_stub.py "天医 星" --别名 医星,天医贵人 --tags 神煞
```

行为：

- 生成 `六壬vault/90-禄命辅助/<slugify(概念名)>.md`
- Frontmatter 与四段模板与 8 张 seed 完全同构
- 若文件已存在，拒绝并 exit code 非零，不覆盖既有内容
