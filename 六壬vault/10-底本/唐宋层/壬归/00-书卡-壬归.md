# 书卡：壬归

## 双轨定位（这本书必须分两个分数）
- **作证据**：参照层，打折。宋撰身份只有书内题署＋今人序说，无宋元著录、无早期刻本。
- **作理解**：★★★ **第一梯队**。卷一提纲例约是六壬文献里少见的结构性总纲，近白话。

详见 `[[壬归-分级修正与理据层定位]]`。

## 使用规则：当提问器，不当答案源
```
《壬归》 → 生成"该问什么"的问题清单
唐宋层   → 回答这些问题
《大全》  → 被这些问题检验
```
⚠️ 讲理据的书最容易把后世理解投射回去。文字越顺越自洽，越要过滤。
从它读到的任何"道理"，先记为待验命题，不得直接写进结论。

## 导入后第一件事：给它测年
拿它的三处取用去比对（见 `[[对校矩阵-五个判别点]]`）：
**站明本一侧（孟仲季、甲戊庚）→ 题宋不可信；站唐本一侧（先干后支、庚辛同组）→ 题宋可信度上升。**
翻卷一就能出结论，不用查目录学。
