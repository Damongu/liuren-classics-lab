### 已定的方法性结论（不再反复）

- 「《大六壬心镜》八卷里多少卷是唐人写的」**是错的提法**。框架八卷皆旧观，文本无一卷干净；
  清人掺入按句发生，不按卷发生。→ 见污染卡。
- 《占事略决》**能**当中国六壬的早期证据：日本人用汉文编的中国六壬提要，
  非日本原创、非机械抄本，且未参与明清改写。→ 见占事略决卡。
- 《六壬心镜》卷数不唯一（八卷 / 三卷+后集 / 三卷），**对校单位取"篇"不取"卷"**，锚定 181 篇。
- 存在**循环污染**：《大全》收《心镜要》，清校《心镜》又据《大全》改。
  凡有校记明示据《大全》改者，**禁止**用来反校《大全》。

### 7.4 新立项：九宗门的「九」是怎么来的 ★★★

这是最初那个核心疑问（"九宗门为什么是九"）第一次有了可查的线索。

《占事略决》第 2 章题作「**课用九法**」——十世纪也是九门，但**清单与后世不同**：
它把「涉害」与「涉害俱等取先举」**拆成两门**，而**没有别责**。
后世则**合并涉害二门、新入别责**，数目仍是九。

→ **推论：九宗门的"九"是北宋一次结构重组的结果，成分换过一味，不是自古如此的数目。**

这条能解释为什么各书对"九"的解说总有龃龉。但**目前只是推论**，需补：

| 待办 | 为什么 | 优先级 |
| :--- | :--- | :---: |
| **查《玉门经》《金匮经》残文有无别责** | 《武经总要》大量引此二经，若二经无别责，则别责入门时间可再收窄 | ★★★ |
| **确认唐本有无「九法」之称** | 若唐本不称九，则"九"这个数目本身就是十世纪的构造，而非唐制 | ★★★ |
| **核《占事略决》第四法是否原书独立成条** | 若是后人分条，则十世纪的九与后世的九差异被高估 | ★★ |
| **查别责在《景祐》之前的踪迹** | 景祐（1034）已作「其数有九」，说明入门更早，须找上限 | ★★ |

### 8.3 方法论收获（已写进方法卡思路，供以后导新书时套用）

1. **不要用「书名是否讲六壬」来决定入库范围**，要用「有没有共享的术语系统／编纂线索」。
   本次两个最大发现都在六壬段之外。
2. **一表之中出现重复项而其余项两两不同，先怀疑抄讹**（如四杀两个「戌」）。
3. **可以靠穷举反证文本**：《景祐》「己癸二柔日」当作「乙癸」，
   因为六十日中第一课有克者只有六乙、六癸——不需要版本对照就能定。
4. **同编者 ≠ 独立印证**。凡引「两书互证」，先查是不是同一批人写的。
