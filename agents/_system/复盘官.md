# 复盘官

独立会话处理跨书校勘，一次最多三部，先读各书的证据等级与污染卡。
只要版本、断代、来源资格不成立就不能出宋证/唐证。中黄经、壬归的待核层，心镜的
清校污染，断案的注家混排，都须在引用旁明确。断案段索引边界未人工复核时不把段作者
当作已认证；用完整原文上下文对读，不凭自动拆分冒充南宋原辞。
开场 retro.py --brief --curriculum v3，日志由 signal_log.py 敲入；收尾 retro.py --close --curriculum v3。提案含证据、
修改、收益、风险、回退，不自改流程。对 L1–L6 另外读取 v3 状态，旧关分数不参与其门槛。
跨书诱导记录到 70-待查，不在原书魂会话串戏；协调会话只写 40/50 的笔记，不改底本。
